# 밤샘 개발 인수 노트 — 2026-09-09

다섯 BANDIT 스킬을 평가하고 필요한 지침·설치 보호·평가 도구를 개선한
**미공개 로컬 작업**입니다. 제품은 여전히 `skills/`의 다섯 스킬이며,
새 PM 런타임이나 별도 업데이트 명령을 추가하지 않았습니다.
커밋·버전 변경·GitHub 릴리스·npm 등록은 하지 않았습니다.

이 문서는 PR 준비 전 밤샘 작업의 인수 기록입니다. 이후 공개 PR을 위해 일부
개인 경로만 익명화했으며, [원본/공개 사본 해시 대응표](../evals/PUBLICATION.md)를
별도로 추가했습니다. 원본 실행 결과와 아래 검증 기록을 새 실행으로 바꾸지 않습니다.

설치기는 사전 검사에서 읽은 정확한 바이트를 유지하고, 쓰기 직전 대상 및
임시 파일의 내용·정체성을 재확인합니다. 복구 중 사용자 편집을 덮어쓰지 않고,
바뀐 잠금 파일을 자기 것으로 간주해 삭제하지 않도록 Node/Python 양쪽을 고쳤습니다.
이전 소스에서 실패한 회귀 검사를 보존했습니다.
관련 기록: [대상 편집/복구](../evals/results/2026-09-08-overnight/README.md),
[잠금 정리](../evals/results/2026-09-09-overnight-round5/checks/lock-cleanup-regressions.md),
[임시 파일](../evals/results/2026-09-09-overnight-round6/README.md).
또한 사용자 지정 기본 폴더 이름이 `pm-craft`일 때 그 폴더 자체를 별도 구버전으로
오인하던 [안내 문구 오류](../evals/results/2026-09-09-overnight-round11/checks/legacy-note-regression.md)를 수정했습니다.

평가 도구는 원본 입력·선택한 스킬·실제 수정 문서와 실행 오류를 보존하고,
입출력 경로 중첩 및 연결된 참조 파일을 검사합니다. 웹 검색은 기본 비활성이고
과제에서 명시적으로 허용한 공개 웹 자료 조사만 켭니다. 선택적 모델 지정은
요청한 식별자만 기록하며 실제
백엔드 정체성을 보증하지 않습니다. [실행 안내](../evals/README.md)의 개발 보조
도구이며 설치 사용자에게 필요한 의존성이 아닙니다.

영어/한국어 사용 안내의 전문 명령, 업데이트 후 재탐색, 사용자 지정 설치 경로
설명을 맞추고 실제 기록에 연결된 예제 세 개를 추가했습니다.

## 평가가 말해 주는 것과 못 말해 주는 것

누적 **48회는 실제 계획 작업 실행 수이지 합격 수가 아닙니다**. 지침 변경에는
새 세션·원시 자료·선택한 스킬만 전달한 후속 실행을 붙였습니다. 기준표와 작성자의
진단은 작업 에이전트에 전달하지 않았습니다. 독립 채점은 비맹검이며,
사례는 개발자가 설계한 합성 자료입니다. 모든 다섯 스킬을 실행했지만,
모델을 고정한 대표 표본·고객 검증·우월성 또는 토큰 절약 실험은 아닙니다.
PM 스킬을 주지 않은 비교 실행(baseline)도 여러 사례에서 같은 기준을 충족했습니다.

다음 결과는 수정하거나 숨기지 않았습니다.

- 명세 길이 초과와 명시적 분모 비교 누락:
  [3차](../evals/results/2026-09-09-overnight-round3/README.md),
  [7차](../evals/results/2026-09-09-overnight-round7/README.md).
  나중의 제한 내 출력만으로 안정적 준수나 숫자 세기 동작이 입증되지는 않습니다.
- 실제 웹 자료 조사에서 당시 페이지 본문/대상 범위의 근거 부족:
  [3차 원본 기록](../evals/results/2026-09-09-overnight-round3/README.md).
- 도서관 PRD가 다섯 기준을 충족해도 단위와 채택일에 근거 없는 서술 두 개가 남았던
  [7차 결과](../evals/results/2026-09-09-overnight-round7/README.md).
- 전사 서비스 리뷰의 날짜 세부정보 부분 충족:
  [8차 결과](../evals/results/2026-09-09-overnight-round8/README.md).
  이전 기준표를 느슨하게 바꾸지 않았습니다.
- 테스트 장치 자체의 실패도 보존했습니다. [로컬 tarball 호출 오류](../evals/results/2026-09-09-overnight-round9/README.md)와
  [가짜 CLI 검사의 문구 기대 오류](../evals/results/2026-09-09-overnight-round12/README.md)는
  별도 수정 실행으로 구분하며 제품 품질 실패/성공 수로 합산하지 않습니다.
- [3차 기록](../evals/results/2026-09-09-overnight-round3/README.md)의 사례 10·14는
  이전 기준표 해시가 별도로 보존되지 않아 실행 전후 동일성을 암호학적으로
  확인하지 못했습니다. 변경의 증거는 아니며, 이후 사례의 사전 기록과 구분됩니다.

과거 [PM Craft 0.1.0 결과](../evals/results/2026-09-07/README.md)와 해당 93개
추적 파일은 기존 이름과 내용으로 보존합니다. 새로운 BANDIT 측정치가 아닙니다.

## 설치·검증·남은 경계

최신 후보는 `dist/overnight-round14/ch4570-bandit-0.4.0.tgz`이며,
SHA-256은 `7f8592028d1b2f350dd304526e57a550c4b133a0f93d5b971d2a133d67bb5f84`입니다.
이번 설치 검사에 사용한 13차 후보와 바이트가 같습니다.
현재 공개 릴리스와 버전 문자열이 같아도 내용은 다른 **미공개 후보**입니다.
후보 검사 명령은 [CONTRIBUTING](../CONTRIBUTING.md), 공개 설치 명령은
[INSTALL](../INSTALL.md)을 사용합니다. 새 공개 버전의 배포 여부는 별도 결정입니다.

최종 전체 검사에서 Node 22.23.2의 **79개**, Python 3.11.16의 **99개** 테스트,
참조 동기화, 저장소 검증, 다섯 메타데이터 검증과 npm 패키징이 통과했습니다.
[14차 기록](../evals/results/2026-09-09-overnight-round14/README.md)은
새 프로젝트 6개의 후보 설치·이전·충돌 거부 검사와 최종 소스 ZIP 검증도 연결합니다.
ZIP과 체크포인트는 `dist/overnight-round14/`에 남깁니다.
구조·단위 검사의 성공은 계획 산출물의 품질 점수와 별개입니다.

설치 보호는 마지막 검사와 실제 파일 조작 사이의 경합을 모두 없애지는 못합니다.
프로세스 충돌/정전까지 보장하는 다중 파일 트랜잭션도 아닙니다. 바뀌었거나 검증할 수
없는 임시·잠금 파일은 보존될 수 있습니다. 로컬 macOS 확인을 모든 운영체제나
모든 호스트의 `$bandit-*` 검색 성공으로 일반화하지 않습니다.

다음 결정은 새 공개 버전 배포와 목표 사용자/호스트를 정한 별도 평가입니다.
현재 파일과 실패 증거를 먼저 검토할 수 있도록 작업 트리를 그대로 남겼습니다.
