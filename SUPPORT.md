# Support

Use [GitHub Issues](https://github.com/ch4570/pm-craft/issues) for installation problems, incorrect instructions, reproducible planning failures, and feature requests. English and Korean reports are welcome.

For an installation issue, include the PM Craft version, operating system, Python version, exact command, and relevant output. For a skill behavior issue, include the host and model when known, how the skill was loaded, the requested task, a sanitized input, the actual output, and the expected product rule.

Keep account credentials, private customer records, unpublished business documents, and local personal paths out of public reports. A small fictional reproduction is enough to explain many problems. Do not paste an entire agent conversation when a short excerpt demonstrates the issue.

Installation success, host discovery, and task quality are separate checks. [Install](INSTALL.md) covers folder and invocation problems; [Validation](VALIDATION.md) records executed checks; [Evaluation](evals/README.md) explains how output quality is assessed.

PM Craft is an instruction package. Model availability, billing, and host tool permissions are managed by the service running your agent. Reports about those services should go to their respective support channels.
