# PM Craft

**제품의 다음 결정을 내리고, 개발자가 이어받을 수 있게 정리합니다.**

[English](README.md) · [v0.1.0](https://github.com/ch4570/pm-craft/releases/tag/v0.1.0) · [설치](INSTALL.md) · [예제](examples/README.md) · [평가](evals/README.md)

PM Craft는 앱·서비스 기획을 돕는 에이전트 스킬입니다. 문제 조사, MVP 범위 선택, 제품 명세 작성, 기존 기획 검토, 결정 변경의 영향 반영을 맡습니다.

고객 근거와 가정을 구분하고, 누가 어떤 조건에서 제품 상태를 바꾸는지 구체화합니다. 계획한 검증과 실제 관측한 결과도 나눕니다. 기존 PRD를 이어서 쓰며, 작은 요청에 새 문서 체계를 요구하지 않습니다.

**스킬 1개 · 목적별 모드 5개 · 한국어·영어 안내 · MIT**

## 바로 사용하기

고정 버전을 받아 프로젝트에 설치합니다. Git과 Python 3.11 이상이 필요합니다. [릴리스 ZIP과 수동 복사](INSTALL.md)도 사용할 수 있습니다.

```sh
git clone --branch v0.1.0 https://github.com/ch4570/pm-craft.git
cd pm-craft
python3 install.py --repo /absolute/path/to/your-project
```

이후 에이전트에 요청합니다.

```text
$pm-craft 이 PRD의 함께 투표하는 규칙을 검토해줘.
누가 표를 바꿀 수 있는지, 언제 확정되는지, 미응답은 어떻게
처리하는지 확인하고 빠진 결정만 제안해. 원본은 수정하지 마.
```

호스트가 `$pm-craft` 호출을 지원하지 않으면 `.agents/skills/pm-craft/SKILL.md`를 읽고 작업에 적용하도록 요청하세요. 스킬 검색과 사용 가능한 도구는 호스트에 따라 다릅니다. [설치와 문제 해결](INSTALL.md).

PM Craft는 지침과 참조 파일로 구성됩니다. 모델·파일 접근·조사 도구는 사용 중인 에이전트가 제공하며 해당 서비스의 사용량과 권한이 적용됩니다. 설치 스크립트는 스킬을 복사합니다. 별도 PM 모델이나 기획용 CLI·API·외부 계정 연결을 제공하지 않습니다.

## 필요한 작업만 선택합니다

| 요청 | 모드 | 받는 결과 |
| --- | --- | --- |
| “만들 만한 문제인지 근거부터 확인해줘.” | Research | 출처, 미검증 가정, 결정에 필요한 실험 |
| “2주 파일럿으로 범위를 줄여줘.” | Decide | 첫 사용을 끝낼 범위, 선택 이유, 뒤로 미룰 기능 |
| “개발자가 구현할 수 있게 구체화해줘.” | Spec | 역할, 조건, 상태 변경, 수용 시나리오 |
| “이 기획의 문제점만 찾아줘.” | Review | 근거가 있는 결함과 수정 제안 |
| “가격을 바꾸고 공유를 추가했어.” | Update | 요구사항·권한·지표의 영향과 유지할 이력 |

다섯 모드를 순서대로 실행할 필요는 없습니다. 좁은 검토는 좁게 끝내고, 이미 채택한 결정은 사용자가 바꾸거나 새 제안을 채택할 때까지 유지합니다.

## 결과물과 검증 범위

[예제](examples/README.md)는 가상의 제품 상황으로 근거·결정·요구사항·확인 방법을 연결합니다. 고객 검증 결과가 아닙니다.

[평가 안내](evals/README.md)에 기획 과제 11회 실행을 기록했습니다. 세 과제를 기본 모델·기존 PM 스킬·PM Craft로 비교하고, PM Craft 두 과제를 추가 확인했습니다. 비교 과제에서는 품질 우위를 입증하지 못했습니다. [검증 기록](VALIDATION.md)에는 도구 테스트 38개와 Linux·macOS·Windows CI 통과를 남겼습니다. 패키지 검사 통과만으로 기획 품질을 입증하지 않습니다.
