$bandit-specify Relayboard를 공개 피드백 보드에서 우리 회사 내부 요청함으로 전환하기로 했어. 기존 PRD와 이번 전환 결정, 연결된 정책·파일럿 기록을 읽고 현재 만들 제품의 명세로 다시 써줘. 옛 공개 보드 목차를 유지할 필요는 없어. 변경 내역만 뒤에 붙이는 대신 권한, 요청 처리 흐름, 이전 공개 링크의 처리, 성공 기준이 같은 제품을 설명하게 해줘.

현재 문서는 `input/docs/PRD.md`야. 이 파일만 수정하고 900단어 이내로 정리해줘. 기존 관측 원문은 그대로 두고 필요한 출처를 참조해줘. 새 제품은 아직 구현하거나 검증하지 않았어. 작은 미정 규칙은 이유가 있는 추천 초안으로 선택해도 돼. 다른 파일 수정, 코드 구현, 제품 테스트 실행은 하지 마. 마지막 답변은 변경 요약과 중요한 미정 사항만 짧게 써줘.
