# 공개 파일럿 및 스테이징 기록

평가용 합성 관측 기록. 실제 고객이나 실제 운영 서비스의 결과가 아니다. 당시 조건을 기록한 원문이며 제품 방향 변경으로 수치를 다시 계산하지 않는다.

## E1 — 공개 참여 파일럿

2026-08-12~25, public-v1. 지역 제품 커뮤니티에서 자원한 36명에게 같은 공개 보드 링크를 보냈다. 로그인 없이 전체 요청을 읽을 수 있었고, 이메일 계정으로 로그인하면 요청을 작성할 수 있었다. 21명이 총 38건을 작성했다. 이들 중 9명이 서로 다른 날에 두 번 이상 작성했다.

초대 수신자 수는 36명이다. 별도 방문 분석이 없어 실제 방문자 수와 방문 후 작성 전환율은 알 수 없다. 내부 업무의 요청자·처리담당자로 참여자를 모집하지 않았고, 처리 시간이나 팀 도입률을 측정하지 않았다. 조직별·프로젝트별 접근 제어나 외부 수신자 지정 공유는 이 버전에 없었다.

## V1 — 당시 공개 열람 확인

2026-08-26, public-v1 스테이징, 새 비로그인 브라우저에서 보드 URL과 개별 요청 URL을 열었다. 두 경우 모두 목록 또는 본문을 읽을 수 있었다. 당시 공개 열람 요구사항에 대해 실행했고 통과했다. 검색엔진 색인에서의 삭제나 이후 버전의 접근 제어를 확인한 기록은 아니다.

## V2 — 보존 작업의 경계 확인

2026-08-26, retention-worker-r3 스테이징. 가짜 시계와 합성 종료 요청 2건을 사용했다. 종료 후 179일인 요청은 남았고 정확히 180일인 요청은 삭제되었다. 이 실행은 통과했다. 접근 화면과 로그인은 경유하지 않았다. 실제 운영 데이터의 처리나 다른 작업 버전에서의 실행을 확인한 기록은 아니다.
