# Relayboard — 공개 피드백 보드 PRD

이 프로젝트와 연결 문서의 조직·사람·기록은 평가용 합성 자료다.

## 공개 보드 진입

D1, 채택 2026-08-11: 보드의 공개 URL을 가진 누구나 요청 목록과 본문을 읽는다. 공개 링크로 관심을 모으는 것이 이번 출시의 중심이다. 검색엔진 공개 노출도 허용한다.

R1: 읽기는 로그인 없이 가능하다. 요청을 쓰거나 본인의 접수 상태 요청을 수정하려면 이메일 계정으로 로그인한다. 다른 사람이 작성한 본문은 수정하지 못한다. 로그인 자체로 조직의 운영 권한을 얻지는 않는다.

## 요청 작성 및 처리

R2: 요청은 제목, 본문, 원작성자, 접수 시각, 상태, 담당자를 갖는다. 상태는 `접수 → 검토 중 → 종료`다. 접수 상태의 작성자는 자기 본문을 고칠 수 있다. 검토 시작 후 본문 수정은 막고 현재 상태를 안내한다. 종료 후 다시 여는 기능은 이번 범위에 없다.

R3: 조직의 처리담당자가 요청을 검토 중으로 바꾸고 담당자를 지정하거나 종료한다. 처리담당자도 원작성자의 본문을 대신 고치지 않는다. 조직 소유자는 처리담당자를 지정한다.

R4: 요청 데이터의 귀속, 기여자 탈퇴, 삭제 권한과 보존 기간은 채택된 [데이터 정책](data-policy.md)이 기준이다. 일반 작성 화면에는 요청 삭제 버튼이 없다.

## 공개 성장 목표

H1: 공개 방문자가 요청을 남기고 다시 방문하면 공개 보드가 반복 피드백 수집에 도움이 될 것이다. 다음 파일럿의 목표는 초대 링크 수신자 중 작성자 비율 50% 이상이다. 목표 수치는 아직 사업 효과를 입증한 기준이 아니다.

E1: 2026-08-12~25 공개 파일럿에서 초대 링크를 받은 36명 중 21명이 요청 38건을 작성했다. 조직의 내부 업무용 이용자는 모집하지 않았다. 출처: [공개 파일럿 기록](public-pilot.md).

## 수용 기준과 실행 기록

A1: 비로그인 방문자가 공개 URL을 열면 요청 목록과 본문을 읽는다.
A2: 작성자가 자기 접수 요청을 수정하면 저장한 본문이 다시 열어도 보이며, 다른 작성자와 검토 중 요청에는 같은 수정이 허용되지 않는다.
A3: 처리담당자가 요청을 종료하면 종료 시각이 기록되고 데이터 정책의 보존 기간 계산이 시작된다.

V1: 2026-08-26 public-v1 스테이징에서 비로그인 링크 열람이 통과했다.
V2: 같은 날 retention-worker-r3의 합성 종료 데이터로 179일 경과 요청 유지와 정확히 180일 경과 요청 삭제가 통과했다. 두 기록의 환경과 한계는 [공개 파일럿 기록](public-pilot.md)에 있다. A2와 실제 운영 중 보존 작업의 실행 결과는 아직 기록하지 않았다.

## 범위

첨부파일, 댓글, 대량 내보내기, 프로젝트 구분, 외부 서비스 동기화는 제외한다. 기존 로그인과 운영 콘솔을 사용한다. 요청 데이터의 조직 귀속과 삭제 정책을 이 PRD에서 별도로 바꾸지 않는다.
