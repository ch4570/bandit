# ChangeDesk — 개인 결제 플로우 명세

## 결제 화면

채택 정책 D1: 프리랜서는 변경 견적을 고객에게 발송하기 전에 건당 9,000원을 결제한다. 구독은 아니다. 버튼 문구는 "견적 보내기 · 9,000원"이다.

## 개인 작성 화면

R1: 견적 작성자만 초안을 편집한다. 동료 공동 작성은 범위 밖이다.
R2: 지정된 고객 담당자의 명시적 수락·거절만 고객 승인으로 취급한다. 링크를 열어본 것은 조회이며 승인이 아니다.
R3: 발송 후 금액이나 납기가 바뀌면 새 제안 버전과 새 고객 승인을 요구한다. 이전 결정은 해당 이전 버전에 보존한다.

## 결제 완료 화면

R4: 결제 성공 전에는 견적 발송을 차단한다. 결제 성공 후 작성자가 발송할 수 있다.

## 매출 화면

H1: 프리랜서당 월 10건 × 9,000원 = 비용·환불 전 월 총매출 90,000원을 가정한다. 월 10건 사용량은 검증되지 않았다.

## 과거 관측

E1: 유료 파일럿에서 8명이 각각 한 건을 결제하고 사용했고, 2명이 환불받았다. 원문: [파일럿 보고서](../observations.md).
V1: 기존 v1 스테이징에서 2026-08-10에 미결제 발송 차단 테스트가 통과했다. 원문: [파일럿 보고서](../observations.md).
V2: 동시 초안 편집은 미구현·미검증이다.
