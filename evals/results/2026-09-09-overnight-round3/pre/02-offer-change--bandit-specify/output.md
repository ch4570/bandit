# ChangeDesk PRD v2 — 무료 공동작성 파일럿

기준일: 2026-09-09. v1을 대체하는 전체 수정본. 근거는 `input/request.md`, `input/current-plan.md`, `input/observations.md`이며, 아래 관측은 제공된 보고서의 기록이다. 구현이나 테스트를 수행하지 않았다.

## 1. 목표와 현재 결정

프리랜서가 변경 견적을 같은 팀 동료와 작성하고, 지정된 고객 담당자에게 명확한 버전의 승인을 받게 한다.

- **D2 채택:** 다음 파일럿부터 건당 9,000원 결제를 없애고 무료로 제공한다. 결제 화면과 미결제 발송 차단을 제거한다. D1을 대체한다.
- **D3 채택:** 같은 팀 동료가 링크로 견적 초안을 공동작성한다. 작성자만 편집할 수 있었던 R1을 대체한다.
- **D4 유지:** 고객 승인·거절 권한은 지정된 고객 담당자에게만 있다. 링크 열람과 승인은 별개이며, 결정은 특정 발송 버전에 귀속된다.

**추천:** 무료 공동작성 파일럿을 진행하되, 목표를 기회가 있었던 사용자의 발송·재사용과 안전한 공동작성 검증에 둔다. 기존 관측만으로 무료화나 공유 기능의 개별 효과, 반복 매출 가능성을 확정하지 않는다.

## 3. 객체와 권한

견적은 작성자, 허용된 팀 동료, 지정 고객 담당자, 편집 가능한 초안과 변경 불가능한 발송 버전을 가진다. 고객 결정은 담당자·결정 시각·버전에 연결한다.

다음 세부 운영 규칙은 **제안 기본값**이다. 링크만으로 팀 자격이나 결정 권한이 생기지 않게 하는 것이 목적이다.

| 주체 | 권한 |
|---|---|
| 작성자 | 초안 생성·편집, 동료 접근 부여·회수, 고객 담당자 지정, 발송 |
| 허용된 같은 팀 동료 | 공유 초안 열람·편집. 발송·권한 변경·고객 결정 불가 |
| 지정 고객 담당자 | 자신에게 발송된 버전 열람, 명시적 승인·거절 |
| 기타 링크 소지자 | 권한 확인 전 견적 열람·편집·결정 불가 |

접근 시 신원과 허용 대상을 확인한다. 구체적인 인증 수단은 미정이다. 접근 회수 후 이미 열린 화면에서도 새 저장을 거절하며, 이전 편집 기록은 남긴다. 담당자는 첫 발송 시 고정하고, 발송 후 교체는 이번 파일럿 범위에서 제외한다.

## 4. 요구사항과 흐름

**R1 개정 — 공동 초안:** 작성자가 견적과 담당자를 지정하고 동료에게 링크를 공유한다. 허용된 동료가 편집하면 저장된 내용과 변경 주체가 다른 편집자에게 보인다.

**R4 개정 — 무료 발송:** 작성자는 결제 없이 발송한다. 발송 버튼은 “견적 보내기”로 표시한다. 저장되지 않은 변경이 있으면 발송 전 해결하게 한다. 발송 실패 시 초안을 보존하고 재시도할 수 있게 하며, 반복 클릭으로 중복 발송하지 않는다.

**R2 유지 — 고객 결정:** 링크 열람은 열람만 기록한다. 지정 담당자의 승인 또는 거절 동작이 성공해야 해당 버전의 상태가 바뀐다. 실패하면 미기록 상태와 재시도 방법을 알린다.

**R3 유지·명확화 — 버전:** 발송된 내용은 고정한다. 금액·납기 변경은 반드시 새 버전으로 만든다. **제안:** 다른 고객 제시 조건 변경도 새 버전으로 처리한다. 수정 초안은 아직 발송된 조건을 바꾸지 않는다. 새 버전을 발송하면 이전 미결정 버전에서는 결정을 막고 최신 버전으로 안내한다. 이전 승인·거절은 원래 버전의 이력으로 남으며 새 조건에 이전되지 않는다.

**R5 제안 — 충돌·복구:** 오래된 초안에서 저장하거나 발송하면 다른 사람의 변경을 조용히 덮어쓰지 않는다. 충돌을 알리고 본인 입력을 보존하여 최신 내용과 비교·재적용하게 한다. 저장 성공은 공유 상태에 반영된 뒤 표시한다.

초안 → 발송·결정 대기 → 승인 또는 거절을 기본 흐름으로 한다. **제안:** 버전당 최초로 성공한 결정 하나를 확정하고 중복 요청은 같은 결과를 반환한다. 결정 번복, 결제·환불 기능, 수익화 실험은 이번 범위에서 제외한다.

## 5. 다음 실험 X2 — 제안

무료 공동작성 조건을 유지한 30일 파일럿을 권한다. 모집 경로별로 나누고 가입일 기준 동일한 관측 기간을 적용한다.

- 가입자 대비 발송자, 실제 견적 기회 보유자 대비 발송자, 후속 기회 보유자 대비 재사용자를 각각 인원수와 함께 기록한다.
- 기회 없음·기회 미수집·관측 진행 중을 분리한다. 동료 참여, 공동작성 후 발송, 충돌·복구, 지원 개입도 기록한다.
- 고객 결정은 버전별로 기록하고 무권한 결정·승인 오귀속 여부를 확인한다.

기회 보유자의 미사용이 이어지면 이유를 확인하고 흐름을 수정한다. 재사용이 반복되고 수동 지원 없이 완료되면 파일럿 확대를 검토한다. 가격·공유의 개별 인과 효과는 후속 분리 실험으로 남긴다. 보편적 합격선은 채택하지 않았으며 수치 기준은 미정이다.

## 6. 원래 기록과 검증 상태

- **D1 폐기:** 견적당 9,000원 선결제. **H1 과거 가설:** 월 10건 × 9,000원 = 비용·환불 전 월 90,000원. 무료 파일럿의 견적 요금 매출은 0원이며 H1은 검증되지 않았다.
- **X1 역사 기록:** 30일 유료 제안에서 결제·전달·환불·재사용 관측. 보편적 합격선 미채택. 결과는 8월 조건에 한정해 보존한다.
- **V1:** v1 스테이징 명시적 승인·거절 전이, 2026-08-10 통과 기록(R2/R3). 당시 통과는 유지하며 새 권한·버전 흐름은 재검증 필요.
- **V2:** 같은 날 v1 스테이징 미결제 발송 차단 통과. 현재 요구가 폐기되어 역사 기록으로만 보존한다.
- **V3:** 동시 편집은 미구현·미시험. 컨시어지 관측으로 대체 검증할 수 없다.

| 동료가 승인 시도, 지정 담당자가 승인 | 동료는 거절, 담당자 결정만 해당 버전에 기록 |
| 승인 후 금액·납기 변경 버전 발송 | 이전 승인 이력 유지, 새 버전 결정 대기 |
| 오래된 링크 결정 또는 저장·발송 실패 후 재시도 | 최신 안내 또는 복구 제공, 허위 성공·중복 결과 없음 |

남은 결정은 인증 수단과 제안한 권한·충돌·버전 운영 규칙의 확정이다. 이는 구현 전 정할 사항이며, 관측된 사실이나 이미 채택된 정책으로 간주하지 않는다.
