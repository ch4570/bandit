# Change-time draft

Synthetic fixture. Unadopted early UI draft, written before the scheduling policy.

1. Customer opens their booking and chooses "Change time".
2. Cancel the original booking to make the new slot picker simpler.
3. Show all free slots. Customer selects one and the browser starts a 2-minute
   timer. If the timer shows time remaining, accept the confirmation.
4. Show "Changed". On an error, tell the customer to start over.

Initial checklist: slot picker works; confirmation button works; success banner.
No implementation or tests exist for this draft.
