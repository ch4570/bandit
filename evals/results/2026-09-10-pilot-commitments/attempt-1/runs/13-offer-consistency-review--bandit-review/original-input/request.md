# 다시신다: 신청을 받기 전에 문서가 같은 약속을 하는지 봐 주세요

아래는 모두 합성 자료인 가상의 운동화 세탁 수거 서비스 `다시신다`입니다. 실제 운영사·고객·주소 정보가 아닙니다.

다음 주에 첫 유료 신청을 받으려 합니다. `approved-offer.md`는 운영 책임자가 확정한 이번 유료 파일럿 조건입니다. `launch-artifacts.md`는 마케팅과 디자이너가 각각 만든 아직 승인 전 초안이고, `trial-record.md`는 이전 무료 시범의 원기록입니다.

**고객에게 하는 주장, 신청 UX, 가격, 실제 수거·세탁·반환이 서로 맞는지**만 한국어로 검토해 주세요. 특히 고객이 광고를 보고 신청·결제한 뒤 실제로 받는 것이 달라지는 곳이 걱정됩니다.

어느 문구·화면·운영 약속이 어떤 근거와 충돌하는지, 고객에게 생기는 문제, 신청을 열기 전에 필요한 최소 수정과 확인 기준을 우선순위로 적어 주세요. 함께 고쳐야 하는 문서는 묶어 주면 좋겠습니다. 근거와 맞는 부분까지 모두 다시 만들 필요는 없습니다. 아직 결정하지 않은 것은 확인이 필요한 항목으로 남겨 주세요.

새로운 시장조사, 전체 PRD, 사업모델 재설계, 법률 자문, 디자인 시안 제작은 요청하지 않습니다. 원본 파일을 수정하거나 외부에 연락하고 실제 신청·결제를 하지 말고 **리뷰 의견만** 주세요.
