# 합성 조사 기록 — 9월 7~9일

아래 여섯 명은 운영자의 지인 작가와 그 소개로 모집한 인터뷰 참여자입니다. 대표 표본이 아니며, 예약·결제·구매 확약은 한 건도 없습니다. 모두 10월 10일 같은 소규모 마켓에 참가할 예정입니다. 식품·화장품은 취급하지 않습니다.

| ID / 작업 | 인터뷰에서 확인한 상황과 발언 |
| --- | --- |
| A / 도자기 컵 | 가격은 붙였지만 크기와 전자레인지 사용 질문을 반복해서 받았다. 대표 상품 3개의 정보와 사진을 이미 정리했다. “3만~5만원이면 고려해요. 틀린 사용 안내가 나가면 안 되니 완성 전에 보고 싶어요.” |
| B / 손바느질 가방 | 혼자 판매해 세탁 방법 설명을 자주 놓친다. 휴대폰 사진은 있지만 문장은 미완성이다. “초안을 보고 말투와 관리법을 고칠 수 있으면 4만원까지 생각해요.” 평일 낮 통화는 어렵고 저녁 문자 확인은 가능하다. |
| C / 자수 소품 | 무료 템플릿으로 가격표를 직접 만든다. “원본 사진과 글을 다 제가 준비하면 돈 낼 이유가 약해요. 1만원이어도 지금은 안 살 것 같아요.” |
| D / 목공 소품 | 판매를 시작한 지 한 달이다. 사진 촬영과 로고 제작까지 함께 원한다. “둘 다 되면 8만원도 생각해요.” 사진·로고를 빼는 경우의 구매 의향은 질문하지 않았다. |
| E / 직조 액세서리 | 주력 제품 3개의 안내를 만들고 싶다. “2만원대면 초안만 받아 제가 고쳐도 돼요. 수정 상담은 없어도 돼요.” 편집 가능한 템플릿이 필요하지만 외부 디자인 도구 사용 경험은 없다. |
| F / 가죽 필통 | 예전 외주에서 한 줄 교정 때문에 일정이 늦어진 경험이 있다. “오탈자만 없으면 제가 확인하는 단계 없이 빨리 받고 싶어요. 3만원이면 비교해 볼게요.” |

A·B는 초안이 도착한 다음 날부터 9월 28일 정오까지, 저녁에 각각 10분 정도 확인할 수 있다고 답했다. “미리 승인”은 할 수 없다. 다른 네 명의 확인 가능 시간은 조사하지 않았다.

운영자의 기존 작가 소식방에는 32명이 있고 그중 위 여섯 명도 포함된다. 관리자는 서비스 모집 게시물 한 번과 마감 알림 한 번을 허용했다. 클릭·구매 기록은 없으며 32명 전원이 마켓 참가자는 아니다. 과거 운영자가 예쁜 안내카드 예시를 올렸을 때 반응 이모지 11개가 달렸지만 가격이나 구매 링크는 없었다.

마켓 공지에는 카드 사용이 의무가 아니라고 적혀 있다. 가격표·안내카드로 매출이 증가했다는 자료는 없다. 구매자가 스마트폰을 꺼내지 않아도 상품 정보를 읽을 수 있는 인쇄물이 좋겠다는 의견은 A·B에게서 나왔다.
