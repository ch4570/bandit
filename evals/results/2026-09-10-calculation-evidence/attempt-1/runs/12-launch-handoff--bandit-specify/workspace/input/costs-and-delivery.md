# 비용과 제공 방식 메모

모든 값은 합성 계산 입력이다. 실제 견적이나 검증된 경제성이 아니다. 비교를 단순하게 하기 위해 아래 금액은 모두 부가세를 제외한 같은 기준으로 쓴다. 세무 설계는 이번 요청 범위 밖이다.

## 월 단위 운영 가정

| 항목 | 계산 기준 | 상태 |
| --- | --- | --- |
| 고정 호스팅·도구 | 전체 월 60,000원 | 소수 점포용 가정. 4주 현금 예산의 100,000원 도구 예약액에 포함해 지출할 항목이며 별도로 두 번 청구하는 비용은 아님 |
| 점포별 저장·알림 | 활성 점포당 월 2,000원 | 임시 견적 |
| 결제 수수료 | 결제 금액의 3.3% | 모델 비교용 가정, 다른 고정 결제 수수료는 이 계산에서 없음 |
| 반복 지원 시간 | 점포당 월 30분 | 5점포 이내를 가정한 추정. 실제 계측 필요 |
| 지원 인건비 환산 | 시간당 25,000원 | 창업자가 무료로 일하더라도 경제성에는 반영하려는 값 |
| 첫 온보딩 | 점포당 한 번 40분 | 반복 지원과 별개. 무료 수동 사용 당시 평균값을 반올림한 추정 |

개발·디자인의 장기 유지비, 획득비, 이탈률, 고객 생애기간은 측정한 적이 없다. 60,000원 고정비를 빼기 전의 점포별 잔여액과, 고정비까지 고려한 전체 손익을 구분해 보고 싶다. 첫 달에는 온보딩 시간이 추가된다.

월 29,000원 점포 정액과 첫 도입비가 있는 더 낮은 월 정액을 메모해 둔 적은 있지만, 확정 가격이 아니다. 다른 요금 구조도 제안해도 된다. 직원 개인에게 비용을 받는 모델을 운영해 본 적은 없다.

## 수동 제공 가능한 범위

- 점포별 인계 양식과 공유 접근 경로 제공.
- 근무 중 직원이 인계 항목을 남기고 다음 교대가 읽었다고 표시.
- 점주가 날짜별 기록을 확인. 직원별 성과 점수는 제공하지 않음.
- 정해진 창업자 업무 시간에 사용 문의를 처리. 실시간 상시 상담은 불가.

외부로 나가는 알림은 현재 가온이 수동으로 보내며, 자동 알림·개인별 수신 설정은 아직 없다. 메시지 발송 수를 늘리는 기능보다 읽음의 의미와 접근 방식부터 정할 필요가 있다는 의견이 개발 메모에 남아 있다. 화면 구성이나 최종 우선순위는 아직 결정하지 않았다.
