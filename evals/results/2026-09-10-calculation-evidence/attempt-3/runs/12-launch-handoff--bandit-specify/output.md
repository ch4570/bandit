# 마감잇 첫 유료 실험 실행·인계안

**잠정 추천은 ‘메모 앱’보다 ‘다음 교대의 읽음 여부를 점주가 나중에 확인하는 인수인계 서비스’다.** 직원 12명 이하 단일 카페에 점포당 월 29,000원으로 제공하고, 최대 5곳에서 시험한다. 자동 알림보다 **읽음의 의미, 출근 후 접근, 점주의 확인**을 먼저 완성한다.

준비 기간은 2026년 9월 14일~10월 11일이다. 아래 가격·정책·판정 기준은 제안이며, 자료의 인터뷰와 사용 기록은 모두 합성이다. 실제 수요나 구현이 검증됐다는 뜻은 아니다.

## 1. 리서치 판단과 첫 타깃

근거는 `input/founder-brief.md`, `input/research-records.md`, `input/costs-and-delivery.md`다. 기존 확정 PRD는 없으며, 이 문서가 첫 실행안이다.

| 근거와 한계 | 이번 선택 |
|---|---|
| 8/18~25 지인·소개 모집: 4점포, 6명. 같은 점포 점주·직원은 독립 점포 표본이 아님 | 시장 전체 수요로 일반화하지 않는다 |
| A 점주는 부재 중 읽음 확인을 원함. 직원은 이중 작성·퇴근 후 답장을 거부 | A와 비슷한 점포를 우선하고, 기록을 다시 채팅에 복사하게 하지 않는다 |
| B는 가격에 회의적이고 무료 사용 후 채팅 복귀. 체크 의미도 혼동 | 무료 채팅 대비 추가 가치와 ‘읽음≠처리 완료’를 검증한다 |
| C는 점주 화면과 직원 순위를 요청 | 날짜별 확인은 포함하되 평가·순위는 제외한다 |
| D 직원은 설치 없는 접근을 선호하지만 점주 의사 미확인 | 직원 관심을 구매 수요로 세지 않는다 |

8/26~9/8 무료 수동 사용에서는 **42회 인계 기회 중 메모 28회, 읽음 20회**였다. 메모 생성률 66.7%, 메모가 있는 기회의 읽음률 71.4%, 전체 기회 대비 읽음률 47.6%다. 가온의 직접 알림은 16회였으나 결과와 교차 집계되지 않았다. 따라서 자발적 사용, 누락 감소, 시간 절약, 유료 전환을 주장할 수 없다. 실제 유료 고객은 0곳이다.

**첫 타깃 가설:** 점주가 모든 교대에 함께 있지 않고, 직원이 재고·남은 일을 종이와 채팅에 중복 전달하는 단일 카페. 점주가 구매·운영 방식에 동의하고 다음 교대 직원이 근무 중 참여할 수 있어야 한다.

가온은 1주차에 다음을 확인한다.

- 점주: 최근 인계 재질문 사례와, 읽음 확인만으로 월 29,000원을 지불할 이유.
- 직원: 출근 시 접근할 기기·경로, 기존 기록 하나를 대체할 수 있는지.
- 양측: 누가 어느 교대에 확인해야 하는지, 미확인 시 매장에서 어떻게 대응하는지.

답변만 수집하지 않고 실제 메모로 시연한 뒤 **동일 조건의 유료 제안**까지 연결한다.

## 2. 첫 제공물과 실행 순서

제공물은 점포별 인계 양식, 근무 중 기록·읽음 표시, 점주의 날짜별 기록 확인, 최초 40분 온보딩, 월 합계 30분 문의 지원이다. 지원은 월·목 14~16시 접수순 처리라는 잠정 운영안으로 제시한다. 실시간 상담과 인계 성공 보장은 없다.

| 기간 | 담당·시간 | 산출물과 다음 단계 조건 |
|---|---|---|
| 9/14~20 | 가온 9h, 소라 4h, 도윤 4h | 기존 점주 3명 후속 대화, 신규 소개 요청, 참여 조건 확인. 소라는 읽음·미확인 화면, 도윤은 접근·저장 가능성 확인 |
| 9/21~27 | 가온 10h, 소라 4h, 도윤 16h | 점주 2명·직원 2명에게 핵심 과제 확인. 작은 웹 흐름 제작, 같은 가격 제안. 9/25에 웹/수동 제공 경로 결정 |
| 9/28~10/4 | 가온 10h, 도윤 8h | 최대 5점포 결제·온보딩, 오류 수정, 교대별 기록 수집. 핵심 경로가 준비된 점포부터 시작 |
| 10/5~11 | 가온 9h | 사용·지원시간·환불·지불 이유 정리, 다음 결제 의향 확인, 유지·수정·중단 결정 |

가온은 총 38/40시간으로 2시간 여유, 도윤 28/28시간, 소라 8/8시간이다. 가온 시간에는 최대 5점포 온보딩·월 반복 지원 **5시간 50분**을 포함한다. 개발 지연 시 기능을 추가하지 않고 점포별 공유 문서와 수동 기록으로 같은 제공물을 전달한다. 점포 분리나 읽음 구분을 보장하지 못하면 해당 경로로 유료 개시하지 않는다.

**포함:** 모바일 웹 또는 공유 문서, 텍스트 인계, 명시적 읽음, 날짜별 점주 확인, 기본 사건 기록, 수동 결제 확인.

**보류:** 앱 설치, 사진, 자동 알림, POS·근무표·급여 연동, 다점포, 직원 평가·순위, 처리 완료 관리. 인계 기회 측정용 교대 시간은 가온이 별도로 기록하며 근무표 기능으로 만들지 않는다.

## 3. 마케팅과 작은 검증 실험

**소개 문구**

> 다음 교대가 읽었는지, 점주가 나중에 확인하세요.  
> 마감잇은 근무 중 남긴 인계와 다음 교대의 읽음 표시를 날짜별로 모읍니다. 앱 설치나 퇴근 후 확인 강요 없이 시작합니다.

**제안·행동 유도**

> 직원 12명 이하 단일 카페 대상, 점포당 월 29,000원(부가세 제외 기준). 최초 40분 안내와 월 30분 문의 지원을 포함합니다. 9월 28일부터 준비된 점포 순으로 최대 5곳에 제공합니다. 자동 알림·실시간 대응·업무 완료 보장은 포함하지 않습니다.  
> **우리 매장 인계로 15분 시연 신청하기**

채널은 가온이 접근 가능한 기존 시연 점주 3명과 소개 가능 신규 점주 5명을 우선한다. 소개 확정·중복 제거 전에는 8개 잠재고객으로 단정하지 않는다. 대안은 운영진이 초안을 허용한 뒤 지역 커뮤니티에 게시하는 것이다. 회원 63명을 노출·구매 분모로 쓰지 않는다. 직원 영상 계정은 점주 비율이 불명확하므로 이번 유료 모집의 주 채널에서 제외한다.

다음 수치는 **작은 표본에서 지출을 통제하기 위한 잠정 기준**이다.

| 관찰 기간·기록 | 판정과 다음 행동 |
|---|---|
| 9/14~27: 가온이 채널, 적격 여부, 실제 제안 수신, 응답, 시연, 결제를 점포별 기록 | 적격 점주에게 완전한 가격 제안이 5건 이상 전달되고 2곳 이상 결제하면 제한 운영. 0곳이면 추가 제작 중단·거절 이유로 제공물 수정. 1곳이면 그 점포만 운영 |
| 첫 사용 7일: 온보딩 완료 점포 중 작성→다음 교대 읽음→점주 확인을 모두 경험한 점포 수 | 2곳 이상 달성하면 반복 관찰. 미달이면 접근·의미 이해 문제부터 수정 |
| 첫 사용 14일: 점포별 인계 기회, 메모, 읽음, 직접 알림 여부, 지원 분 기록 | 인계 기회 5회 이상인 2점포 이상에서 전체 기회 대비 읽음률 60% 이상이면 제한 지속. 알림 유무별 원수치를 함께 보고 인과효과는 주장하지 않음 |

제안 전달이 5건 미만이거나 교대 기회·관찰 기간이 부족하면 수요 실패가 아니라 **판단 유보**다. 10/11에 14일이 지나지 않은 점포는 이후 확인일을 잡는다. 갱신 의향은 갱신 결제와 구분하고, 반복 결제는 각 점포의 다음 청구일에 확인한다.

## 4. 디자이너·개발자 인계

인계 항목은 점포·작성 교대·본문·작성자 표시·시각·버전을 가진다. 상태는 **작성 중 → 게시·미확인 → 다음 교대 읽음**이다. 읽음은 전달 내용을 확인했다는 뜻이며 업무 완료가 아니다.

| 화면 | 내용 순서·행동·상태 |
|---|---|
| 점주 시작 | 대상 조건 → 제공 범위·가격·지원·해지 조건 → 점포 설정 → 근무 중 접근 경로 안내. 수동 결제 확인 전에는 대기 상태 |
| 직원 첫 진입 | 점포명 → 근무 중 이용 안내 → 역할·이름 표시 선택 → 인계 목록. 빈 화면은 ‘아직 등록된 인계 없음’이며 ‘인계 완료’가 아님 |
| 인계 작성 | 다음 교대 표시 → 남길 일 → 게시. 고객 얼굴·연락처 입력 금지 안내. 저장 실패 시 본문 유지·재시도, 저장 확인 전 성공 표시 금지 |
| 다음 교대 확인 | 미확인 항목 우선 → 본문·작성 시각 → ‘내용을 읽었습니다’. 아래에 ‘처리 완료를 뜻하지 않습니다’ 명시 |
| 점주 확인 | 날짜 → 메모 없는 교대·미확인·읽음 구분 → 항목 상세. 직원별 점수·순위 없음 |

**권한 제안:** 직원은 자기 점포 기록을 보고 작성하며 자기 항목을 정정한다. 지정된 다음 교대 직원의 명시적 확인만 인계 읽음으로 반영한다. 점주가 보기만 해서는 읽음이 되지 않는다. 직원용·점주용 접근 경로를 분리하고 공유 링크 기반 이름 표시는 본인 인증이 아님을 밝힌다. 직원 변경·링크 유출 시 가온이 경로를 교체하며 기존 기록은 보존한다.

게시 후 본문 정정은 새 버전으로 남기고 다시 미확인 처리한다. 이전 읽음은 이전 버전에만 남는다. 중복 클릭은 읽음 수를 늘리지 않는다.

예정 교대 시작 후 30분까지 미확인이면 ‘확인 필요’를 표시한다는 잠정 규칙을 쓴다. 자동 메시지는 보내지 않는다. 점주는 근무 중 직접 확인하고 시스템 밖 전달은 ‘구두 전달’로 별도 기록한다. 퇴근 직원에게 응답을 요구하지 않는다.

모바일에서 큰 터치 영역, 명시적 레이블, 키보드 조작, 색 외 상태 문구를 제공한다. 소라의 과제는 “작성→읽음→점주 확인”과 “실패 후 재시도”다. 4명 모두 읽음과 완료를 구분하고 직원 2명이 도움 없이 핵심 과제를 끝내는 것을 출시 전 목표로 삼는다.

## 5. 사업모델과 돈이 남는 조건

두 모델 모두 점주가 점포 단위로 결제하고 동일 제공물을 받는다. 직원에게 과금하지 않는다.

| 부가세 제외 원화 | A: 월 29,000원 | B: 도입비 29,000원＋월 19,000원 |
|---|---:|---:|
| 반복 월 결제 수수료 | 957 | 627 |
| 점포당 반복 공헌액 | 13,543 | 3,873 |
| 온보딩 포함 첫 달 공헌액 | -3,124 | 15,249 |
| 5점포 반복 월 손익 | 7,715 | -40,635 |
| 5점포 첫 달 손익 | -75,618 | 16,247 |
| 반복 고정비 손익분기 | 5점포 | 16점포 |

**계산 확인:** 실제 계산 도구 반환값을 원 단위 반올림했다. 반복 공헌액은 `월요금×0.967−2,000−0.5×25,000`, 첫 달은 여기에 `도입비×0.967−40/60×25,000`, 전체 손익은 `공헌액×5−60,000`이다. 입력은 비용 메모다. 첫 달 손익의 반올림 전 반환값은 A -75,618.33원, B 16,246.67원이었다.

A를 잠정 추천한다. 초기 결제 부담이 낮고 지원 한도 5점포 안에서 반복 고정비를 가까스로 충당한다. B는 첫 달 회수에는 유리하지만 반복 손익분기 16점포가 현재 지원 한도를 넘는다. 두 모델 모두 획득비와 장기 개발·디자인 유지비는 빠져 있으므로 완전한 순이익이 아니다.

지원이 월 60분이면 점포당 반복 공헌액은 A 1,043원, B -8,627원으로 악화된다. 실제 지원 초과나 A 구매 거절이 반복되면 추천을 재검토한다. B는 유료 수요와 지원 축소 가능성이 함께 확인될 때만 후속 제안으로 시험한다.

**결제 정책 제안:** 서비스 개시일에 선결제, 한 달 제공, 자동 갱신 없음. 개시 전 취소는 전액 환불, 제공자 중단은 미제공 기간 비례 환불한다. 실제 판매 전에 가온이 청구 통화·세금 표시·결제 수단을 확정한다.

현금 배정은 도구 100,000원, 모집 100,000원, 과제 사례비 120,000원, 소재 30,000원, 결제비 10,000원, 점포 변동비 10,000원, 돌발비 130,000원으로 **500,000원**, 미배정 **300,000원**이다. 월 고정비 60,000원은 도구 예약액 안에 포함한다. 사례비는 구매와 무관하게 지급하고 구매 보조금으로 쓰지 않는다. 인건비 환산은 위 경제성에만 반영하며 매출을 예산 확대 근거로 쓰지 않는다.

## 6. 완료 조건과 남은 판단

출시 전 예정 인수 확인은 다음과 같다.

- 직원이 게시하면 다른 근무 기기와 점주 화면에 같은 내용이 보인다.
- 다음 교대가 열기만 하면 미확인, 명시적으로 누르면 읽음이며 완료로 표시되지 않는다.
- 읽은 내용을 정정하면 새 버전은 미확인이고 과거 확인은 보존된다.
- 저장 실패·다른 점포 접근·폐기된 링크는 성공으로 처리되지 않으며 복구 방법을 안내한다.
- 메모 없음과 미확인이 구분되고, 정해진 시간 이후에도 자동 퇴근 알림은 발생하지 않는다.

가온은 1주차에 접근 기기·교대 규칙, 2주차에 결제 조건, 4주차에 지원시간과 수요를 판단한다. **계산만 도구로 확인했으며, 사용성·인수 확인·모집·결제는 모두 미실행 계획이다.** 파일 변경이나 외부 연락은 하지 않았다.
