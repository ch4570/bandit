## 4. 디자이너에게 전달할 핵심 흐름

모바일 우선으로 화면 상단에 점포·교대·날짜, 그다음 미확인 항목, 마지막에 행동 버튼을 둔다.

| 화면·역할 | 요구와 상태·복구 |
|---|---|
| **R1 시작 / 점주** | P1 가격·기간·지원·취소 조건 → 수동 신청·결제 확인 → 점포 접근 설정. 결제 대기는 활성으로 표시하지 않는다. 점주 관리 경로와 직원 경로를 분리한다 |
| **R2 인계 작성 / 직원** | 현재·다음 교대, 인계 내용, ‘저장하기’. 저장 성공 후에만 등록 완료. 실패하면 입력을 유지하고 재시도. 빈 화면은 ‘아직 기록이 없습니다’로 표시하며 ‘인계할 내용 없음’을 명시적으로 남길 수 있게 한다 |
| **R3 출근 확인 / 다음 교대 직원** | 미확인 내용 → ‘읽었어요’. 안내: ‘읽음은 작업 완료가 아닙니다.’ 열람만으로 읽음 처리하지 않는다. 반복 클릭은 중복 처리하지 않는다 |
| **R4 날짜별 확인 / 점주** | 기록 있음/내용 없음/미작성, 읽음/미확인을 구분. 개인 순위 없음. 미확인은 근무 중 다음 담당자에게 기존 매장 경로로 확인하고, 퇴근 직원에게 응답을 요구하지 않는다 |

읽음은 **해당 내용 버전에 대한 다음 교대의 확인**이다. 수정 대신 정정 기록을 추가하고 정정분은 새로 확인받는다. 과거 읽음을 새 내용으로 이전하지 않는다.

직원은 자기 점포 기록·읽음만 수행하고, 점주는 접근 회수·재발급을 관리한다. 공유 접근은 개인 신원을 증명하지 않으므로 ‘누가 읽었는지’ 개인 인증을 약속하지 않는다. 접근 만료 시 점주에게 재발급을 요청하며 기존 기록은 보존한다. 장애 중에는 매장 종이/채팅으로 인계하고 복구 후 대체 경로 사용 사실을 남긴다.

**계획된 확인 V1:** 직원 3명에게 설치 없이 기록·읽음·저장 실패 재시도를 수행하게 하고 읽음 의미를 설명받는다. 점주 2명에게 미작성과 미확인을 구분하게 한다. 읽음을 완료로 오해하면 출시 전 문구·버튼을 수정한다. 큰 터치 영역, 명시적 레이블, 키보드 접근, 색상 외 상태 문구를 포함한다. 아직 수행 결과는 없다.

## 5. 사업모델과 결정을 뒤집을 조건

동일한 점포 단위 제공물을 비교한다. 직원에게는 과금하지 않는다.

| 월 기준, 원 | A: 월 29,000원 | B: 도입비 29,000원 + 월 19,000원 |
|---|---:|---:|
| 반복 결제 수수료 3.3% | 957 | 627 |
| 저장·알림 2,000원 차감 후 현금 잔여 | 26,043 | 16,373 |
| 반복 지원 30분=12,500원 차감 후 점포별 기여액 | **13,543** | **3,873** |
| 첫 달 기여액: 온보딩 포함, B 도입비 순수입 포함 | −3,124 | 15,249 |
| 5점포 반복월: 고정비 60,000원 차감 | **7,715** | **−40,635** |
| 5점포 첫 달: 고정비 차감 | −75,618 | 16,247 |
| 반복월 손익분기 점포 수 | 5 | 16 |

계산식은 `가격×0.967−2,000−지원시간×25,000`; 온보딩은 별도 **16,667원/점포**다. B는 도입비로 초기 비용을 회수하지만 반복월 손익분기 16곳이 지원 한도 5곳을 넘는다. **A를 잠정 추천**하되, 5곳 확보도 미검증이며 유지개발·획득비·이탈을 제외한 7,715원은 지속 가능한 순이익의 증거가 아니다.

A의 지원 시간이 월 15/30/60분이면 5점포 반복월 잔여는 각각 **38,965/7,715/−54,785원**이다. 지원이 30분을 넘거나 갱신이 부족하면 가격·지원 범위를 다시 설계한다. B는 반복 지원 감소 또는 월 가격 수정으로 5곳 이내 경제성이 성립할 때만 재검토한다.
