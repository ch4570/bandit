기간: **2026년 9월 14일~10월 11일**, 한국시간. 준비 2주, 유료 제공 2주로 나눈다. 기존 정식 명세는 없으며 아래는 신규 제안이다. 확정된 자원·제외 범위를 준수하되, 가격·운영 규칙·판정 기준은 잠정안으로 둔다.

모든 근거는 제공된 **합성 자료**다. 실제 수요를 검증한 문서가 아니며 연락·게시·결제·제품 검증은 실행하지 않았다.

- 점주: 최근 다시 물어본 인계 사례는 무엇이며, 읽음 기록만으로 어떤 판단이 가능한가?

- 양쪽: “읽음은 처리 완료가 아니다”를 같은 뜻으로 이해하는가?
- 구매자: 아래 14일 제공물에 실제로 결제하는가? 거절 이유가 가격·가치·접근 방식 중 무엇인가?

답변만 모으지 않고 **원형 과제 → 같은 조건의 판매 제안 → 결제 후 사용**으로 이어간다.

## 2. 하나의 제공물과 출시 범위

자동 갱신은 없다. 시작 전 취소는 전액 환불하고, 제공자 사유로 이용 불가능한 날은 일할 환불한다. 종료 후 계속 사용할 조건은 별도 제안하며, 첫 실험 결제를 월 구독 유지로 해석하지 않는다.

**필수:** 모바일 웹 또는 동일 규칙의 점포별 공유 문서, 텍스트 인계, 교대 지정, 명시적 읽음, 날짜별 점주 조회, 접근 회수, 기본 측정 기록.

**보류:** 처리 완료 관리, 자동 알림, 개인별 알림 설정, 사진 첨부, 다점포 권한, POS·근무표·급여 연동, 직원 성과 평가, 앱 설치·결제 화면. 실시간 상시 상담과 퇴근 후 개인 기기 확인을 요구하지 않는다.

## 5. 디자이너·개발자 인계

**공통 규칙:** 점포에 교대별 인계 항목이 속한다. 항목은 내용·작성 시각·대상 교대·읽음 시각을 가진다. 개인 실명 인증을 제공하지 않으므로 “누가 확실히 읽었다” 대신 **해당 교대의 읽음 표시**로 표현한다.

| 화면 | 내용 순서·주요 행동·상태 |
|---|---|
| 도입 안내 | 대상·14일 제공 내용·가격·종료·환불 → 참여 요청. 가온이 조건과 결제를 수동 확인한 뒤 접근 제공 |
| 직원 첫 진입 | 점포·현재 교대 확인 → “근무 중 사용 / 읽음≠완료” → 인계 목록. 최초 빈 화면은 “아직 등록된 인계가 없습니다”; “남은 일 없음”으로 단정하지 않음 |
| 작성 | 대상 교대 → 인계 내용 → 저장. 고객 얼굴·연락처 입력 금지 안내. 저장 실패 시 입력 보존·재시도, 저장 확인 전 성공 표시 금지 |
| 다음 교대 | 미확인 항목 우선 → 내용 → “읽었습니다”. 페이지 열기만으로 읽음 처리하지 않음. 표시 후 시각과 취소 동작 제공 |
| 점주 조회 | 날짜 → 메모 없음·미확인·읽음 구분 → 항목 상세. 점주 조회는 직원 읽음 상태를 바꾸지 않음 |

점포 공용 직원 접근과 점주 전용 접근을 분리한다. 직원은 작성·읽음 표시, 점주는 조회·접근 회수 요청, 가온은 승인된 설정·지원만 수행한다. 직원 경로로 점주 기능에 접근할 수 없어야 한다. 공유 기기를 우선하고, 퇴사·링크 유출 시 접근을 교체해 기존 경로를 차단한다.

저장된 본문은 직접 덮어쓰지 않고 정정 항목을 추가한다. 정정에는 새 읽음이 필요하다. 반복 클릭은 중복 기록을 만들지 않으며 읽음 취소 이력은 남긴다. 인계가 안 됐으면 근무 중 다음 담당자에게 기존 매장 연락 방식으로 확인하고, 시스템이 대신 알렸다고 표시하지 않는다.

모바일 세로 화면, 명확한 버튼 이름, 충분한 글자 크기, 키보드 접근, 색상 외 상태 문구를 적용한다. 소라는 직원 3명에게 작성·읽음·정정 과제를 주고 “읽음이 처리 완료인가”를 설명하게 한다. 한 명이라도 혼동하면 문구를 수정하고 다시 확인한다.

## 6. 사업모델과 계산

두 안 모두 점주가 점포 단위로 지불하고 같은 핵심 기능·지원 범위를 받는다.

| 월 모델 | A: 월 29,000원 | B: 도입비 30,000원＋월 19,000원 |
|---|---:|---:|
| 반복 결제 수수료 | 957원 | 627원 |
| 점포별 반복 잔여액 | 13,543원 | 3,873원 |
| 첫 달 잔여액, 온보딩 포함 | −3,124원 | 16,216원 |
| 5점포 반복 전체 손익 | 7,715원 | −40,635원 |
| 5점포 첫 달 전체 손익 | −75,618원 | 21,082원 |
| 반복 손익분기 점포 수 | 5곳 | 16곳 |

`costs-and-delivery.md` 기준으로 반복 잔여액은 `월요금×0.967−2,000−25,000×0.5`, 첫 달은 여기에 `도입비×0.967−25,000×40/60`, 전체 손익은 `점포수×잔여액−60,000`이다. 도입비는 실제 온보딩 제공 대가다.

**A를 잠정 추천한다.** B는 초기 설정비를 회수하지만 반복 손익분기 16곳이 지원 한도 5곳을 넘는다. A도 5곳을 채워야 겨우 양수이며, 모집·개발·디자인 유지비를 반영하기 전이다.

A의 지원 시간이 월 15/30/60분이면 5곳 반복 손익은 각각 **38,965/7,715/−54,785원**이다. 약 34분을 넘거나 유료 5곳 확보가 어려우면 가격 인상·지원 축소를 검토하고, 수요가 받쳐주지 않으면 확대하지 않는다.

14일 실험은 월 요금의 절반이지만 월 구독과 별도 상품이다. 지원 15분, 온보딩 40분, 점포비 2,000원과 고정비 60,000원을 보수적으로 전액 반영하면 5곳 경제적 손익은 **−114,476원**, 해당 직접 현금 잔여는 **108원**이다. 모집·소재비는 여기서 추가로 차감된다. 따라서 이번 실험은 수익 사업 검증을 위한 학습 비용이다.

계산은 이 문서 작성 중 JavaScript로 실행했으며 위 반환값과 대조했다. 원 단위 표시는 반올림했다. 계산 정확성이 비용 가정의 타당성을 입증하지는 않는다.

## 7. 출시 전 확인과 남은 결정

다음은 **계획된 인수 시나리오이며 미실행**이다.

- 직원이 저장하면 다른 기기에서 같은 내용이 보인다. 실패하면 성공 표시 없이 재시도할 수 있다.
- 다음 교대가 읽음을 누르면 점주에게 시각이 보이지만 업무 완료로 표시되지 않는다.
- 정정 전 읽음은 유지되고 정정 항목은 미확인으로 남는다.
- 빈 교대·미확인 교대가 구분되고, 반복 클릭·취소가 기록을 왜곡하지 않는다.
- 직원 링크로 점주 기능에 접근할 수 없고 회수된 링크는 차단된다.
- 결제 안내·온보딩·종료 안내의 가격, 기간, 인원 한도와 환불 규칙이 일치한다.

가온은 9/20까지 접근 기기·지원 시간대를 확정하고, 9/25까지 환불·기록 보관 기본안인 “종료 후 30일 보관 후 삭제”를 안내문에 반영한다. 도윤은 같은 날 웹 또는 공유 문서의 권한·저장·회수 가능성을 확인한다. 가온은 10/11에 결제·반복 사용·지원비를 함께 보고 연장, 제안 수정, 중단을 결정한다.
