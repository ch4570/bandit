# 이전 무료 시범 원기록 — 2026-08-25 회차

합성 자료. 첫 유료 파일럿과 다른 조건의 작은 운영 시범이다.

대상은 솔빛 A 한 곳이었다. 지인의 소개를 받은 8가구가 1켤레씩 맡겼다. 세탁비·수거비를 받지 않았고, 운영자가 현관 앞에서 직접 수거했다. 처음에는 “다음 날 반환을 목표로 한다”고 안내했다.

| 기록 항목 | 수치·내용 |
| --- | --- |
| 접수·세탁 | 8켤레 |
| 수거 다음 날 반환 | 6켤레 |
| 이틀 뒤 반환 | 2켤레 — 추가 건조가 필요해 연락 후 반환 |
| 만족도 질문 응답 | 8가구 중 5가구 응답 |
| 만족 응답 | 응답한 5가구 모두 “만족” 선택 |
| 유료 재구매 | 가격을 제시하거나 재구매를 받지 않음 |
| 살균 관련 검사 | 수행하지 않음 |

내부 회의 메모: 다음 시범에서는 이동 시간을 줄이기 위해 보관함을 쓰기로 했다. 건조 여유를 확보한 화요일 수거·금요일 반환으로 변경했고, 두 단지 합산 세탁·건조 용량 24켤레를 운영 담당자가 확인했다. 이 변경은 `OPS-0910`에 반영되었다.
