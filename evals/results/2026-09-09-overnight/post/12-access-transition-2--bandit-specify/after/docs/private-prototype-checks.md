# 내부 요청함 프로토타입 확인 메모

평가용 합성 관측. 2026-09-04, internal-preview-2 스테이징에서 개발자가 실행한 범위만 적었다. 실고객의 업무 파일럿이 아니다.

## V3 — 당시 조직 전체 열람

현재 초대 명단에 있는 테스트 계정 4개가 조직 안의 요청 목록과 본문을 읽었다. 그중 2개는 요청의 `인사` 표시와 관계없는 구성원 계정이었다. 당시 프로젝트는 접근 단위가 아니었으므로 이것도 조직 전체 열람 요구사항에 맞게 통과 처리했다. 다른 조직의 테스트 계정 3개는 같은 요청 URL에서 접근이 거부되었다.

구성원을 명단에서 제외한 뒤 새 페이지 열람이 거부되는 것은 1개 계정으로 확인했다. 제외 전에 열어둔 편집 화면의 저장과 프로젝트별 접근은 실행하지 않았다. 외부 진행 카드는 프로토타입에 없었다.

## 구현 논의

개발 메모: “현재는 요청 조회 시 조직 ID만 비교한다. 요청마다 프로젝트 표시를 추가하더라도 일단 이 조회 조건을 유지하면 변경량은 적다.” 공수 추정은 하지 않았다. 제품 책임자의 채택 결정이나 보안 검토를 받은 제안은 아니다.

retention-worker-r3, 기존 데이터 귀속 정책과 종료 시각 계산은 이 프로토타입 작업에서 변경하지 않았다. 보존 작업은 이 날짜에 다시 실행하지 않았다. 처리 속도, 현업 사용률, 공개 버전 대비 성과는 측정하지 않았다.
