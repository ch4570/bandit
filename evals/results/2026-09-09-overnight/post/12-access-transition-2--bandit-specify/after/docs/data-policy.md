# Relayboard 데이터 정책

평가용 합성 정책. 제품 책임자가 2026-08-11 채택했으며 공개 보드와 이후 내부용 버전에 공통 적용한다. 이 문서가 데이터 귀속·보존·삭제의 기준이다.

- P1 — 요청과 처리 기록은 요청이 속한 조직의 데이터다. 작성자의 개인 소유 문서로 취급하지 않는다. 작성자가 조직에서 탈퇴해도 원작성자 표시와 요청 기록은 유지한다. 담당자 변경은 원작성자를 바꾸지 않는다.
- P2 — 종료한 요청은 종료 시각부터 정확히 180일 동안 보존한 뒤 삭제한다. 아직 종료하지 않은 요청에는 이 만료 시각이 없다. 작성자 탈퇴나 열람 권한 철회는 조기 삭제나 보존 시계 재시작의 사유가 아니다.
- P3 — 잘못 입력한 민감정보 등으로 조기 삭제가 필요한 경우 조직 소유자만 기존 운영 콘솔에서 요청을 삭제할 수 있다. 일반 작성자나 처리담당자는 소유자 검토를 요청한다. 이 검토는 수동 운영이며 새 삭제 승인 기능을 개발할 계획은 없다.
- P4 — 조직 소유자 변경 시 데이터는 계속 같은 조직에 남는다. 별도 조직으로 이전하는 기능은 지원하지 않는다.

접근 권한은 제품의 현재 접근 정책에 따르며, 데이터를 보존한다는 이유로 탈퇴자에게 계속 열람 권한을 주지는 않는다. 종료 시각은 서버 기록을 사용한다. 백업 파기 방식이나 법정 보존 의무를 이 합성 제품 정책에서 확정한 것은 아니다.
