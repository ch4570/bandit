# 내부 요청함 전환 결정

평가용 합성 결정 기록. 제품 책임자가 2026-08-31 채택했다.

공개 커뮤니티용 출시를 중단하고 같은 조직 구성원 사이의 업무 요청을 받는 내부 요청함으로 전환한다. 고객 문제나 아직 발표하지 않은 작업이 본문에 들어오므로 새 요청과 기존 요청 모두 공개로 남겨두지 않는다.

이번 버전의 접근 단위는 조직 전체다. 기존 사내 로그인으로 신원을 확인하고, 조직 소유자가 관리하는 초대 명단에 현재 포함된 사람만 그 조직의 모든 요청을 읽고 새 요청을 만들 수 있다. 과거 공개 파일럿의 이메일 계정이나 공개 링크를 가진 사실만으로 초대된 구성원이 되지는 않는다. 다른 조직의 로그인 사용자도 접근할 수 없다.

소유자는 구성원을 추가하거나 제외하고 처리담당자를 지정한다. 제외된 구성원은 다음 요청부터 열람·작성·수정을 할 수 없어야 한다. 이미 열어둔 편집 화면에서 저장을 눌러도 마찬가지다. 요청 귀속과 데이터 보존은 기존 데이터 정책을 따른다. 본문 편집과 `접수 → 검토 중 → 종료` 처리 규칙은 유지한다.

예전 공개 보드와 요청 URL은 로그인과 현재 조직 접근 권한 확인을 거쳐야 한다. 비로그인 화면에 요청 제목·본문·작성자 정보를 내보내지 않는다. 이미 외부에서 저장하거나 색인한 공개 내용을 제품이 소급 회수할 수 있다고 약속하지 않는다.

첫 내부 파일럿에서는 지정된 한 팀이 실제 업무 요청을 등록하고 담당자가 검토를 시작할 수 있는지 확인하고 싶다. 아직 팀을 모집하거나 이 버전을 실행한 결과는 없다. 실행 기준의 구체적인 관찰 기간이나 작은 안내 문구는 추천 초안으로 정해도 된다.

프로젝트별 접근, 외부 고객 공유, 댓글, 첨부파일, 내보내기는 이번 범위 밖이다. 기존 사내 로그인과 운영 콘솔은 사용 가능한 의존성으로 전제한다. 이 전환은 채택했지만 배포 완료를 의미하지 않는다.
