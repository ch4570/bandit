# Relayboard — 내부 요청함 PRD

평가용 합성 자료다. 내부 버전은 미구현·미검증이며 수용 기준은 실행 예정이다.

## 방향과 범위

D2 — **채택**, 제품 책임자, 2026-08-31: [전환 결정](private-intake-decision.md)에 따라 공개 보드를 조직 내부 업무 요청함으로 전환한다. 고객 문제·미발표 작업을 보호하도록 기존·신규 요청 모두 조직 접근 정책을 적용한다. 공개 URL 열람·검색엔진 노출을 허용한 D1(2026-08-11)은 대체된 이전 정책이다.

목표는 지정 팀의 실제 요청 등록부터 담당자의 검토 시작까지다. 접근 단위는 조직 전체다. 기존 사내 로그인·운영 콘솔은 사용 가능한 의존성이다. 프로젝트 구분·접근, 외부 고객 공유, 댓글, 첨부파일, 내보내기, 외부 동기화, 종료 후 재개는 제외한다.

## 접근과 역할

R1 — 사내 로그인으로 신원을 확인하고 소유자가 관리하는 해당 조직 초대 명단에 **현재 포함된 사람**만 조직 전체 요청을 열람·등록한다. 과거 파일럿 이메일 계정, 공개 링크 소지, 타 조직 로그인은 접근 자격이 아니다.

| 역할 | 권한 |
| --- | --- |
| 현재 구성원 | 전체 요청 열람·등록, 자신의 접수 요청 본문 수정 |
| 처리담당자 | 구성원 권한과 검토 시작·담당자 지정/변경·종료. 타인 본문 대리 수정 불가 |
| 조직 소유자 | 구성원 추가/제외, 처리담당자 지정, 운영 콘솔 조기 삭제 |
| 비로그인·미초대·제외된 사람·타 조직 사용자 | 해당 조직 요청 접근·변경 불가 |

**추천 초안:** 접근 우회를 막도록 소유자·처리담당자도 현재 구성원이어야 한다. 소유자의 처리 권한은 별도 지정한다.

R5 — 구성원 제외는 다음 요청부터 적용한다. 열린 편집 화면의 저장, 새로고침, 직접 접근에도 현재 권한을 확인해 거절하고 접근 종료를 안내한다. 이미 전달한 화면 내용의 회수는 보장하지 않는다. 원작성자·요청·처리 기록은 유지한다. **추천 초안:** 제외된 담당자는 활동 불가로 표시하고 현재 처리담당자가 재지정한다. 이력 보존과 후속 처리를 위한 초안이다.

## 요청 처리와 데이터

R2 — 요청은 한 조직에 속하며 제목·본문·원작성자·접수 시각·상태·담당자·종료 시각을 갖는다. 등록하면 `접수`, 담당자 미지정, 종료 시각 없음으로 저장한다. 성공하면 재열기로 결과를 확인한다. 실패하면 성공 표시 없이 입력 유지·재시도를 제공한다. 권한 상실 시에는 저장을 거절한다.

접수 상태의 원작성자만 자기 본문을 수정한다. 저장 시 권한·상태를 확인하고 검토가 시작되었으면 거절·안내한다. 검토 중·종료 본문은 수정할 수 없다.

R3 — 처리담당자가 `접수 → 검토 중 → 종료`로 처리한다. **추천 초안:** 책임자 명확화를 위해 검토 시작에 담당자를 지정하며 재지정을 허용한다. 순서를 건너뛰거나 종료를 재개하지 않는다. 종료 시 서버 시각을 기록한다. 경쟁 동작으로 상태가 바뀌면 최신 상태를 안내하며 되돌리거나 종료 시각을 재기록하지 않는다. 변경은 구성원에게 공유된다.

R4 — [데이터 정책 P1–P4](data-policy.md)가 귀속·보존·삭제의 기준이다. 조직 데이터와 원작성자는 탈퇴·담당자 변경에도 유지된다. 종료 시각부터 정확히 180일 보존 후 삭제하며 미종료 요청에는 만료가 없다. 접근 철회·탈퇴는 조기 삭제나 보존 시계 재시작 사유가 아니다. 조기 삭제는 소유자만 기존 운영 콘솔에서 수행한다. 작성자·처리담당자는 수동 검토를 요청하며 일반 삭제 버튼·새 승인 기능은 없다. 소유자 변경에도 같은 조직에 남고 조직 간 이전은 지원하지 않는다.

## 이전 공개 링크

R6 — 기존 보드·개별 요청 URL에도 로그인과 현재 조직 권한 확인을 적용한다. 비로그인 화면·응답·미리보기에 제목·본문·작성자를 노출하지 않고 로그인으로 안내한다. 로그인 후 권한이 있으면 원래 목적지를 보여주고, 없으면 내용 없이 접근 불가와 소유자에게 초대를 요청하는 방법을 안내한다. 직접 데이터 요청도 동일하다. 삭제 요청은 구성원에게 이용 불가로 안내한다.

전환 시 모든 기존 데이터·공개 경로를 보호하며 검색엔진에도 공개하지 않는다. 이미 외부에 저장·색인된 사본의 소급 회수는 약속하지 않는다.

## 성공 기준과 역사적 근거

H2 — 내부 업무에 도움이 되는지는 미확인이다. **추천 파일럿 초안:** 지정 팀 접근 설정 후 14일간 초대 인원, 실제 업무 요청 작성자 수·요청 수, 담당자 지정과 검토 시작까지 이어진 요청 수를 기록한다. 실제 요청 1건 이상의 등록→담당자 지정→검토 시작이 목표다. 완결 경로 확인용이며 도입률·효율 개선의 증거는 아니다. 미실행·기록 누락·완료 사례 없음을 구분한다. 모집·실행 결과는 없다.

[E1 원문](public-pilot.md): 2026-08-12~25 public-v1 공개 커뮤니티 파일럿에서 링크 수신자 36명 중 21명이 38건을 작성했고 9명은 서로 다른 날 반복 작성했다. 역사적 관측이다. 방문자·방문 전환율은 불명이며 내부 참여자 모집·처리 시간·도입률 측정은 없었다. 기존 H1의 수신자 대비 작성자 50% 목표는 내부 기준에서 제외한다.

## 예정 수용 시나리오

- A1 대체(R1·R6): 이전 보드·요청 URL을 비로그인으로 열면 정보 없이 로그인 안내. 미초대·타 조직·파일럿 계정만으로 접근하면 거절. 현재 구성원은 전체 요청 열람.
- A2(R2): 자기 접수 본문 저장·재열기 시 내용 유지. 타인·검토 중·종료 본문 수정과 편집 도중 검토가 시작된 저장은 거절.
- A3(R3·R4): 검토·종료 후 공유 상태와 서버 종료 시각 확인. 중복 종료에도 시각 불변. 종료 후 179일 유지·정확히 180일 삭제, 미종료 유지.
- A4(R1·R3): 등록 후 접수 요청 재열기 가능. 일반 구성원 처리 시도는 거절. 처리담당자 지정·검토 시작은 다른 구성원에게 반영. 저장 실패는 성공 안내 없이 복구 가능.
- A5(R5): 화면을 연 뒤 구성원 제외 시 다음 열람·저장·처리 거절. 다른 구성원은 원작성자·기존 기록을 계속 확인하며 보존 기한 불변.
- A6(R4): 일반 작성자·처리담당자 삭제는 거절. 소유자 콘솔 조기 삭제 후 요청 이용 불가. 소유자 교체에도 조직 귀속 유지.

[V1·V2 원문](public-pilot.md): V1은 2026-08-26 public-v1 스테이징의 비로그인 공개 열람 통과다. 역사적 결과이며 내부 접근은 재검증 필요하다. V2는 같은 날 retention-worker-r3 스테이징의 가짜 시계·합성 종료 데이터로 179일 유지/180일 삭제가 통과했다. 보존 규칙과 해당 조건에는 유효하나 내부 접근·운영·다른 버전의 검증은 아니다. A2와 운영 보존 결과는 미기록이며 내부 시나리오 전체는 예정·결과 미관측이다.

미정: 추천 규칙·파일럿 기준 채택, 팀·일정·기록 담당자. 정책의 백업 파기·법정 보존 의무도 미확정이다.
