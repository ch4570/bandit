# ShelfNote screen sketch — 2026-09-06

Synthetic fixture. Unadopted idea sketch written before the first-trial scope
and capacity were settled. There is no implementation behind these screens.

## Home

An aisle map with pins for recent shelf problems; tapping a pin opens details.

## New report

Choose a shelf, write a note, and attach a photo. Show a result after Send.

## Inbox

A shared feed of new reports. A later iteration could add assignments, due
dates, comments, and a history of edits.

## My reports

Show the employee's reports and their handling state. A later iteration could
add email updates so the employee does not need to reopen the app.

## Dashboard

Charts of report counts by aisle and elapsed handling time.
