## 5. 디자이너 인계: 핵심 화면과 규칙

**R1—역할:** 점주가 점포 개설·청구에 동의하고 직원 접근을 허용한다. 직원은 작성·읽음, 점주는 날짜별 조회와 접근 회수를 맡는다. 점포 간 기록은 격리한다. 공유 접근에서 남긴 교대 표시는 개인 신원 증명이 아니므로 ‘누가 확실히 읽었다’고 표현하지 않는다.

| 화면 | 내용 순서·주요 행동·상태 |
|---|---|
| 점주 시작 | 대상 조건→제공 방식·기간·가격·환불→참여 동의→근무 중 접근 경로·교대 확인 담당 설정. 결제 확인은 가온이 수동 처리한다. |
| 직원 첫 진입 | 점포명→‘읽음≠처리 완료’ 안내→현재 교대 선택→남은 인계. 설치 없이 접근한다. |
| 인계 작성 | 다음 교대·전달 내용→저장. 업무 없으면 ‘전달 사항 없음’을 명시해 미작성과 구분한다. |
| 다음 교대 확인 | 미확인 우선 목록→항목 내용→‘읽었습니다’. 열기만 해서는 읽음이 되지 않는다. 확인 시각·교대를 표시한다. |
| 점주 확인 | 날짜→미작성/전달 사항 없음/미확인/읽음→상세. 성과 순위나 처리 완료 추정은 표시하지 않는다. |

**R2—복구:** 저장 중·저장 실패·저장 완료를 구분하고 실패 시 입력을 유지한다. 읽음 중복 클릭은 하나의 기록으로 남긴다. 읽은 항목이 정정되면 이전 기록을 유지하고 새 내용은 재확인 대상으로 표시한다. 잘못된 읽음은 취소 이력을 남긴다.

인계가 없으면 다음 교대가 근무 중 정해진 매장 경로로 확인한다. 가온은 상시 알림을 보장하지 않는다. 접속 장애 시 점포 양식에 기록하고 복구 후 옮기되 원래 시각과 수동 이관 여부를 남긴다. 회수된 접근은 재접속을 막고 점주 문의 경로를 보여준다.

모바일 우선, 명확한 버튼 이름, 충분한 글자 크기, 키보드 조작, 색 외 상태 문구를 요구한다.

**V2—예정된 수용 확인:** 소라는 직원 2명·점주 1명에게 인계 작성, 읽음, 정정 후 재확인, 점주 미확인 찾기를 맡긴다. 도움 없이 완료하는지와 ‘읽음=완료’ 오해를 기록한다. 도윤은 같은 기록의 다른 기기 재조회, 권한 회수, 저장 실패·재시도를 확인한다. 현재 모두 미실행이다.
