# 마감잇 첫 유료 실험 실행·디자인 인계안

**권고: ‘메모 앱’보다 ‘다음 교대의 읽음 여부를 점주가 나중에 확인하는 인수인계 서비스’를 먼저 검증한다.** 직원은 근무 중 한 번 기록하고, 다음 교대는 읽음을 표시한다. 점주는 날짜별 인계 상태를 본다. 누락 감소나 업무 완료는 약속하지 않는다.

기간은 **2026년 9월 14일~10월 11일**이다. 아래 가격·운영 규칙·판정 기준은 창업자가 위임한 범위에서 작성한 **잠정 제안**이다. 자료는 모두 합성이므로 실제 수요나 성과의 증거가 아니다. 기존 완성 명세는 없으며, 원본 변경 없이 새 실행안을 작성했다.

## 1. 자료가 지지하는 선택과 남은 질문

8/26~9/8 기록은 **4개 점포의 인터뷰 6명 중 3개 점포가 참여한 무료·수동 지원 실험**이다. 인계 기회 42회 중 메모 28회(66.7%), 메모가 있는 기회 중 읽음 20/28회(71.4%), 전체 기회 대비 읽음은 20/42회(47.6%)다. 직원 수를 독립 점포 표본처럼 세지 않는다.

직접 알림은 16회였지만 읽음과의 교차 집계가 없어 자발적 사용률을 계산할 수 없다. 사전 비교, 물건 누락·시간 절감 측정, 결제 동의가 없으므로 **효과·유료 수요·자동 운영 가능성은 모두 미확인**이다.

가온이 1주차에 먼저 확인할 질문은 다음과 같다.

- 점주: 최근 인계를 다시 물어본 실제 상황은 무엇이며, 읽음 기록만으로 구매할 이유가 있는가?
- 직원: 기존 종이·채팅 기록을 하나 줄일 수 있는가? 읽음과 완료를 구분하는가?
- 양측: 다음 교대와 확인 예정 시각을 정할 수 있는가? 매장 내 접근 기기가 있는가?
- 점주: 아래 가격·수동 제공 조건을 보고 실제 결제하는가?

인터뷰 답변만으로 결론 내리지 않고, 화면 과제·결제·교대별 사용 기록으로 확인한다.

## 2. 하나의 제공물과 출시 범위

**첫 타깃:** 직원 12명 이하 단일 카페 중, 점주가 일부 교대에 부재하고 인계 확인을 반복해서 묻는 곳. 직원 사용자와 구매·도입 결정자인 점주 모두 참여해야 한다.

**유료 제안 v1:** 9/21~10/11의 **3주 한정 실험, 점포당 29,000원, 도입비 없음**, 최대 5곳. 다음 기간은 월 29,000원 제안이며 자동 갱신하지 않는다. 실험 기간과 월 구독 기간을 구분해 안내한다.

제공물은 점포별 접근 경로, 인계 작성·읽음 표시, 점주 날짜별 조회, 40분 온보딩, 정해진 업무시간의 문의 대응이다. 수동 제공 가능성을 처음부터 고지한다. 지원 시간은 월·수·금 13~14시로 제안하고 다음 지원 시간까지 답변한다. 상시 상담이나 교대마다 운영자가 재촉하는 서비스는 포함하지 않는다.

**이번에 포함:** 텍스트 인계, 다음 교대 지정, 읽음 시각, 미확인 상태, 점주 조회, 접근 회수, 최소 로그. 사진은 고객 정보 유입과 개발 부담 때문에 보류한다.

**보류:** 자동 알림, 외부 연동, 별도 앱, 결제 화면, 근무표·급여, 다점포, 직원별 점수·순위, 처리 완료 관리. 근무표는 만들지 않고 점주가 확인 기회만 수동 등록한다.

**제공 조건:** 시작 전 취소 또는 약속한 핵심 흐름을 제공하지 못하면 전액 환불. 시작 후 자발적 중단은 종료 요청 다음 날부터 남은 일수/21로 일할 환불하며 원 단위 반올림한다. 제공 기간 종료 시 쓰기를 닫고, 점주에게 기록을 전달한 뒤 7일 내 운영 사본을 삭제한다. 후속 제공은 새 동의가 있어야 한다.

## 4. 마케팅과 작은 검증 실험

**소개 문구**

> 교대 메모, 다음 근무자가 읽었는지 확인하세요.  
> 마감잇은 근무 중 인계를 남기고 읽음을 표시하며, 점주가 날짜별 기록을 확인하는 서비스입니다. 읽음은 업무 완료를 뜻하지 않습니다.  
> 직원 12명 이하 단일 카페 대상, 9/21~10/11 3주 실험 29,000원·도입비 없음. 최대 5곳에 공유 문서 또는 모바일 웹과 수동 지원을 제공합니다.

**행동 유도:** “점주용 10분 설명과 참여 조건 받기”

가온은 1주차에 기존 시연 점주 3명부터 후속 대화를 준비하고, 소개 가능한 신규 점주 5명은 실제 연결된 경우에만 접촉 대상으로 센다. 이는 연락 가능한 **최대 후보 경로**이며 확보 고객 8곳이 아니다.

부족하면 같은 문구로 지역 커뮤니티 운영진에게 초안 검토를 요청하는 계획을 사용한다. 게시 승인이 없으면 노출 0으로 기록한다. 회원 63명을 실제 도달로 계산하지 않는다. 직원 영상 계정은 구매자 구성이 불명확해 이번 판매 주력에서 제외한다. 모든 연락·게시·집행은 문서 수령 후 가온의 실행 결정 사항이다.

**측정은 점포 단위, 채널·제안 버전별로 기록한다.**

| 단계 | 정의·기간 | 잠정 판정과 다음 행동 |

수치는 작은 실험의 의사결정 기준이지 통계적 확증이 아니다. 모든 기회에 메모·읽음·운영자 알림 여부를 교차 기록하며, 누락 데이터가 있으면 판정을 보류한다. 획득비는 **실제 모집·소재 지출÷신규 결제 점포**, 가온의 획득 시간 환산액을 더한 값도 병기한다. 기존·신규 고객을 분리한다.

## 5. 디자이너 인계: 역할과 화면

**핵심 객체:** 점포 → 날짜·다음 교대별 인계 묶음 → 메모와 읽음 기록. 읽음은 해당 묶음의 특정 내용 버전에 대한 다음 교대의 명시적 확인이다. 개인의 신원이나 업무 완료를 증명하지 않는다.

| 화면 | 콘텐츠 순서·행동·상태 |
|---|---|
| 점주 도입 | 대상 조건 → 가격·기간·수동 지원·환불 → 참여 요청. 가온이 조건 동의를 기록하고 수동 결제 확인 후 활성화 |
| 첫 접근 | 점포명 → 현재/다음 교대 선택 → “읽음≠완료, 근무 중 사용” → 시작. 직원용 매장 접근 경로와 점주 전용 접근을 분리 |
| 인계 작성 | 다음 교대·예정 시각 → 텍스트 → 저장. 빈 기록 대신 ‘인계할 내용 없음’을 명시적으로 선택 |
| 다음 교대 | 미확인 묶음 우선 → 전체 내용 → ‘읽었습니다’. 페이지 열람만으로 읽음 처리하지 않음 |
| 점주 조회 | 날짜 → 미확인/읽음/내용 없음 → 시각과 변경 이력. 순위·개인 점수 없음 |

직원은 해당 점포의 기록을 읽고 추가하며 다음 교대 역할에서 확인한다. 공유 접근이므로 작성자 개인을 검증했다고 표시하지 않는다. 점주는 조회와 접근 회수를 담당하고 직원 대신 읽음을 누를 수 없다. 가온은 지원에 필요한 점포만 취급한다.

저장 후 원문을 덮어쓰지 않고 정정 내용을 추가한다. 정정 시 이전 읽음은 이력으로 남기고 새 내용은 재확인이 필요하다. 중복 확인은 한 번으로 계산하며, 오래 열린 화면에서 확인하면 최신 내용을 먼저 보여준다.

예정 시각이 지나도 읽음이 없으면 ‘확인 예정 시각 지남’으로 표시한다. 점주는 다음 근무 중 확인을 요청한다. 직원 개인 기기에 퇴근 후 알림을 보내지 않는다. 빈 목록, 저장 중, 저장 실패, 접근 만료를 문구로 구분하고, 실패 시 입력을 보존해 재시도하도록 한다. 접근 회수 후 기존 기록은 유지한다.

모바일 우선으로 큰 동작 버튼, 명시적 라벨, 키보드 접근, 색상 외 상태 표시를 요구한다. 1주차 직원 과제에서 **작성→교대 변경→읽음**을 수행하고 읽음의 뜻을 설명하게 한다. 점주는 미확인 인계를 찾는다.

**예정 인수 확인:** 저장 후 재접속해 기록 유지, 열람만으로 미확인 유지, 정정 후 재확인 요구, 중복 확인 1회, 타 점포 접근 차단, 회수된 경로 차단, 저장 실패 복구, 점주 대리 확인 불가를 확인한다. 아직 실행하거나 통과한 검사는 없다.
