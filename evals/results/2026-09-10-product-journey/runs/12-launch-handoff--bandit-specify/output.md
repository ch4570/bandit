# 마감잇 첫 유료 실험·디자인 인계안

2026년 9월 14일~10월 11일 실행안. 모든 근거는 제공된 **합성 자료**이며 실제 시장 검증 결과가 아니다. 별도 기존 PRD는 없어 창업자 기록을 기준으로 새로 구성했다. 인력·예산·제외 범위는 주어진 제약이며, 아래 타깃·가격·운영 규칙·판정 기준은 **잠정 제안**이다.

**추천: 직원이 근무 중 한 번 남긴 인계를 다음 교대가 읽고, 점주가 날짜별 확인 상태를 보는 서비스를 먼저 판다.** 앱 완성보다 이 흐름에 돈을 내고 반복 사용하는지 확인한다.

**첫 타깃:** 직원 12명 이하 단일 카페 중, 점주가 일부 교대에 부재하고 종이·채팅 재질문이 있으며 매장 안에서 웹 링크를 열 수 있는 곳. 구매·도입 승인자는 점주, 사용자는 교대 직원이다. A형 점포부터 시작하되 A의 구매를 전제하지 않는다.

무료 채팅은 익숙하고 추가 비용이 없다. 마감잇의 가설적 차이는 메시지 수가 아니라 **인계 내용과 다음 교대의 확인 상태를 함께 남기는 것**이다. 이 차이가 불필요하면 전환 이유도 없다.

먼저 확인할 질문은 다음 행동에 연결한다.

- 가온, 9/18까지: 점주에게 최근 재질문 사례와 지불 주체 확인 → 문제·구매 권한 없는 점포 제외.
- 소라, 9/20까지: 직원이 읽음을 완료로 오해하는지 과제 관찰 → 혼동하면 문구·상태 수정.
- 가온, 9/27까지: 같은 조건의 유료 제안에 실제 결제하는지 확인 → 희망 발언과 결제 분리.
- 가온, 10/11까지: 직접 알림 없이 사용되는지, 지원이 얼마나 드는지 기록 → 반복 제공 여부 결정.

## 2. 하나의 제안과 출시 범위

**실험 제안:** 9/28~10/11, 점포당 14,500원, 최대 5점포. 직원별 과금 없음. 점포별 양식·공유 접근 경로·읽음 표시·날짜별 점주 조회·40분 온보딩을 제공한다. 이후 월 29,000원은 재구매 검증용 잠정 가격이며 자동 갱신하지 않는다. 모든 금액은 입력 자료와 동일한 부가세 제외 비교 기준이다.

지원은 가온이 평일 12~13시 중 확인하고 다음 평일까지 답변하는 방식으로 제안한다. 즉시 대응과 교대별 알림은 판매 약속에 넣지 않는다. 근무 중 사용하며 퇴근 후 확인을 요구하지 않는다.

시작 전 취소는 전액, 시작 후 중도 종료는 미사용 일수/14 비율로 환불한다. 제공 불능 기간도 같은 기준으로 환불하고 중복 환불하지 않는다. 최종 청구금액과 조건은 결제 전에 서면 확정한다.

**필수 범위:** 모바일 웹 또는 동등한 공유 문서, 점포 분리, 직원 접근과 점주 관리 권한 분리, 작성·읽음·날짜 조회, 실패 표시와 재시도, 최소 사용 로그.

**보류:** 자동 알림, 개인별 수신 설정, 앱 설치, 업무 완료 관리, 직원 순위, 다점포 권한, POS·근무표·급여 연동. 별도 결제 화면 대신 가온이 서면 동의와 입금·환불을 관리한다.

9/24까지 웹 핵심 흐름이 준비되지 않으면 공유 문서로 전환한다. 제공 형태를 결제 전에 알리고, 읽음 의미·점포 분리·점주 확인을 충족하지 못하면 판매하지 않는다.

## 5. 디자이너에게 넘길 흐름·규칙

**객체:** 점포, 대상 교대가 있는 인계 항목, 그 항목 버전에 대한 읽음 기록, 점포별 이용 계약. 개인 성과 데이터는 만들지 않는다.

점주는 계약·접근 경로 관리·날짜 조회를 한다. 직원은 매장 내 공유 접근으로 작성·읽음을 수행한다. 공유 접근은 개인 신원을 증명하지 않으므로 **‘누가 읽었는지’나 전원 확인을 표시하지 않는다.** 점주 관리 접근은 분리한다. 가온은 지원을 위해 필요한 점포만 접근한다.

| 화면 | 정보 순서·주요 행동·상태 |
|---|---|
| 참여 안내 | 대상 → 제공물·수동 방식 → 기간·금액 → 지원·환불 → 참여 요청. 점주만 계약 진행 |
| 첫 사용 | 점포명 → ‘읽음≠완료’ → 퇴근 후 확인 불필요 → 연습 항목. 직원 접근과 점주 화면을 각각 안내 |
| 직원 홈 | 대상 교대 → 미확인 항목 → 읽은 항목 → ‘인계 남기기’. 기록 없음은 ‘작성된 인계 없음’으로 표시 |
| 작성 | 인계 내용·대상 교대 → 저장. 고객 얼굴·연락처 입력 금지 안내. 저장 성공 후 목록에 반영 |
| 항목 상세 | 내용·작성 시각·대상 교대 → ‘읽었습니다’. 열람만으로 읽음 처리하지 않음 |
| 점주 조회 | 날짜 → 미확인/읽음 항목 → 기록 상세. ‘읽음은 처리 완료나 전원 확인이 아닙니다’ 상시 표시 |

저장된 항목은 덮어쓰지 않고 정정 항목으로 연결한다. 정정에는 새 읽음이 필요하며 이전 기록은 남긴다. 같은 항목의 반복 읽음은 한 번만 집계한다. 실수한 읽음은 해당 교대에서 취소할 수 있고 취소 이력을 남긴다.

대상 교대가 지났는데 읽음이 없으면 **‘확인 기록 없음’**으로 남긴다. 점주는 근무 중 기존 연락 수단으로 확인한다. 긴급 인계는 기존 연락 수단을 사용하며 자동 전달을 보장하지 않는다.

저장 실패 시 입력을 유지하고 재시도를 제공한다. 재시도 중복 저장을 막고, 오프라인에서는 성공 표시를 하지 않는다. 접근 만료·차단은 점주에게 근무 중 문의하도록 안내한다. 접근 경로 회수는 과거 기록을 삭제하지 않는다.

종료 후 직원 쓰기를 닫고 점주에게 기록 사본을 제공한 뒤 30일 내 삭제하는 운영을 제안한다. 소라는 큰 터치 영역, 명시적 라벨, 키보드 접근, 색상 외 상태 문구를 스케치에 반영한다.

원 단위 반올림. 획득비·장기 개발/디자인 유지비 전 손익이며 실제 이익을 검증한 값이 아니다.

**A 잠정 추천:** 도입 장벽이 낮고 5점포 한도 안에서 반복 비용을 충당할 가능성이 있다. 다만 여유가 극히 작다. B는 첫 달 회수가 좋지만 지속 손익분기가 지원 한도를 넘는다.

이번 14일 실험은 A의 절반 가격으로 별도 검증한다. 보수적으로 점포별 비용을 월 전액 반영하면:

**14,500 × 0.967 − 2,000 − 12,500 − 16,667 ≈ −17,145원/점포.**

5점포에 고정비까지 빼면 약 **−145,728원**, 획득비 전 경제적 손실이다. 이는 현금 지출과 다르며 학습 비용으로 관리한다. 14일 결제가 월 29,000원 수요를 입증하지는 않는다.

A도 지원이 월 60분이면 잔여액이 1,043원으로 떨어지고 5점포 전체는 −54,785원이다. 반복 지원 과다, 월 가격 거절, 직원 사용 저조 중 하나가 확인되면 확대를 멈춘다. B는 도입비 수용과 지원 감소 또는 반복 가격 인상이 함께 확인될 때만 다시 검토한다. 미측정 유지율로 LTV를 만들지 않는다.

## 7. 인수 확인과 남은 결정

아래는 **계획된 확인이며 실행·통과 기록이 아니다.** 9/24 도윤·소라가 웹 또는 수동 대안에서 확인한다.

- 직원이 저장하면 재접속과 점주 화면에 같은 항목이 보인다.
- 다음 교대가 열기만 하면 미확인, 명시적으로 읽음을 누르면 읽음으로 바뀌고 완료로 표시되지 않는다.
- 정정 후에는 새 읽음이 필요하고 중복 누름은 집계를 늘리지 않는다.
- 저장 실패 시 입력이 남고 성공으로 오인하지 않는다.
- 다른 점포 접근과 직원의 관리 권한 사용이 차단된다.
- 읽음 없는 인계가 점주 화면에 남고 회복 방법이 안내된다.
- 점주가 결제 전에 기간·금액·수동 제공·환불·자동 갱신 없음을 설명할 수 있다.

9/20까지 가온은 매장 내 접근 가능성과 지원 시간을, 9/27까지 청구·환불 절차를 확정한다. 소라는 직원 2명·점주 1명 이상에게 ‘작성→읽음→점주 확인’ 과제를 관찰한다. 한 명이라도 읽음을 업무 완료로 이해하면 수정 후 다시 확인한다. 이후 운영 여부는 10/11의 결제·사용·지원 비용 기록으로 결정한다.
