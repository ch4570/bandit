# 전달받은 검증 기록

합성 기록. 아래 실행일과 통과 표시는 이 사례에 제공된 가상 과거 보고이며,
실제 제품의 테스트 로그나 개인정보 유출 여부를 증명하는 자료가 아니다.

기록 정리일: 2026-10-14. 아래 검사는 2026-10-09에 v0.3의
`begin_download`를 대상으로 실행했다고 보고되어 있다. v0.3은 요청 중
즉시 묶음을 만들었으며, 10월 13일의 비동기 작업 전환 전 버전이다.

| 검사 | 준비 조건과 확인한 내용 | 보고 결과 |
| --- | --- | --- |
| `test_other_requester_denied` | A가 요청한 준비된 묶음에 로그인한 B가 접근하면 `PermissionError` | 통과 |
| `test_expired_bundle_denied` | 요청한 A라도 요청 시각의 24시간 뒤에는 `PermissionError` | 통과 |

두 검사는 고정된 허용 목록을 사용했다. 요청 뒤 권한 철회, 생성 중 철회,
여러 프로젝트 중 하나의 철회, 파일 전송 시작 시의 권한 변경은 검사하지
않았다. v0.4 비동기 흐름을 다시 실행한 결과나 브라우저/운영 환경의
종단 간 결과는 이 기록에 없다. 이전 통과 표시를 취소한 기록도 없다.
