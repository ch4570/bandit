$bandit-review 동네 제작자 전시회 모아전의 [사진 전달 PRD 초안](delivery-prd.md)을 검토해줘. 연결된 승인 정책, 정적 코드, 검증 기록을 함께 보고 이번 배포 판단에 중요한 발견을 최대 3개로 우선순위화해줘. 파일 근거, 사용자에게 생기는 영향, 필요한 수정이나 결정, 다음 확인을 설명해줘. 이미 맞게 동작하는 부분과 정해진 제외 범위는 불필요하게 바꾸지 마. 한국어로 450개 공백 구분 단어 이내로 답해줘. 모든 자료는 합성이며 실제 고객 자료가 아니다. 제공 파일만 읽고, 파일 수정, 코드나 테스트 실행, 웹 탐색, 연락, 외부 작업은 하지 마.
