# ChangeDesk — 무료 팀 공동 작성 PRD

## 목표와 채택 결정

[현재 요청](../request.md)에 따라 개인 유료 도구를 무료 팀 공동 작성으로 전환한다.

- **D1 대체:** 건당 9,000원 결제를 폐지한다. 공동 작성·발송은 무료이며 결제 화면·발송 전 결제 조건·매출 화면을 제거한다.
- **D2 유지:** 공동 작성 권한과 고객 승인 권한은 별개다. 지정 고객 담당자의 명시적 수락·거절만 결정이며 조회는 승인이 아니다.
- **D3 유지:** 발송 후 금액·납기 변경은 새 버전·새 승인을 요구한다. 수락 이후 변경도 동일하다. 이전 결정은 원래 버전에 보존한다.

**추천 초안**은 미확정 제안이다. 무료 팀의 사용·재사용 효과는 미검증이다.

## 범위와 권한

MVP: 팀 생성·초대, 공동 작성, 무료 발송, 고객 결정·이력. 제외: 결제·구독·환불, 실시간 커서·댓글·내부 결재.

**추천 초안:** 팀 생성자는 관리자로서 이메일 초대·멤버 제거를 담당한다. 초대를 수락한 로그인 팀원은 팀 견적을 조회·편집한다. 견적 생성자는 책임자로서 고객 지정·발송·철회를 담당한다. 관리자가 책임자를 제거하려면 다른 팀원에게 책임을 이전한다. 제거된 멤버는 기존 세션에서도 접근·저장할 수 없으며 과거 기여 이력은 보존한다.

고객은 자신에게 발송된 버전 조회·수락·거절만 가능하고 초안을 편집하지 못한다. **추천 초안:** 지정 이메일로 보낸 일회용 코드로 고객을 확인한다. 링크 소지나 팀원 자격만으로 고객 조회·결정 권한을 얻지 못한다.

## 객체와 상태

- **견적:** 팀, 책임자, 고객 담당자, 제목·변경 내용, 금액·통화, 납기. 금액은 통화 최소 단위, 납기는 날짜·시간대로 표시한다. 제안 금액과 이용료는 별개다.
- **공유 초안:** 팀원이 수정하는 미발송 내용으로 고객에게 숨긴다.
- **제안 버전:** 발송 시 고정한 내용, 버전 번호, 발송자·시각, 지정 고객. 직접 수정하지 않는다.
- **고객 결정:** 대상 버전·담당자·수락 또는 거절·시각. 조회 기록과 분리한다.

**추천 초안:** 승인 대기 → 수락·거절·철회·대체됨. 완료된 결정은 수정하지 않는다. 새 초안은 이전 버전에 영향을 주지 않는다. 새 발송은 이전 대기 버전을 대체한다. 과거 수락·거절은 보존하되 새 버전에 승계하지 않는다. 변경 승인 전에는 기존 수락 조건과 변경 승인 대기 조건을 구분한다. 변경 거절은 기존 수락 조건을 대체하지 않는다.

## 흐름과 복구

**R1 대체 — 공동 작성:** 팀원이 만들고 동료가 편집한다. **추천 초안:** 저장 중·완료·실패를 표시한다. 성공한 저장은 동료 재조회에 반영한다. 오래된 저장은 덮어쓰기를 거절하고 최신·미저장 내용을 보여줘 수동 조정·재시도하게 한다. 자동 병합은 제외한다.

**R4 대체 — 무료 발송:** 책임자가 필수 내용·고객을 확인해 ‘무료로 보내기’를 실행한다. 결제를 요구하지 않는다. **추천 초안:** 확인한 초안이 바뀌면 재검토한다. 성공 시 고정 버전·고객 공유 링크를 제공한다. 실패 시 오류를 표시하고 초안을 보존해 재시도하게 한다. 중복 클릭·재시도는 같은 발송 하나만 생성한다. 경쟁 발송은 하나만 확정하고 나머지는 최신 상태 재확인을 요구한다.

**R2 유지 — 고객 결정:** 담당자가 전체 제안·버전을 확인하고 수락·거절한다. 저장 성공 후 팀과 고객에게 같은 결과를 표시한다. 실패는 미완료로 알리고 재시도한다. **추천 초안:** 동일 결정 재시도는 중복 기록하지 않고 상반된 결정은 먼저 확정된 하나만 인정한다.

**R3 유지 — 수정·재승인:** 발송 내용을 새 공유 초안으로 복사한다. 금액·납기 변경은 새 버전으로 발송해 재승인받는다. **추천 초안:** 모든 발송 내용 변경과 담당자 교체에도 새 버전·승인을 적용한다. 이전 링크는 이력을 보여주되 대체·철회된 버전의 결정을 차단한다. 최신 버전은 현재 담당자에게만 안내한다. 철회는 대기 버전에만 허용한다. 결정과 대체·철회가 경쟁하면 먼저 확정된 상태를 적용하고 후속 동작은 재확인을 요구한다.

## 과거 근거와 검증 한계

[과거 보고서](../observations.md) 원문은 보존한다. 다음은 **가상 개발 평가용 자료**이며 실제 고객 증거가 아니다.

- **E1 — 역사적 한정:** 2026-08-31 기준 개인 작성·건당 9,000원 조건의 30일 파일럿에서 프리랜서 8명이 각각 결제하고 한 건을 발송했다. 2명은 전액 환불받았다. 8명 모두 후속 기회가 있었고 2명이 재사용했다. 무료 팀 제품의 수요·재사용 증거로 전용하지 않는다.
- **V1 — 당시 실행·통과:** 2026-08-10 v1 스테이징의 미결제 발송 차단 R4 테스트. 역사적 통과는 유효하나 무료 발송·공동 작성은 검증하지 않는다. 대체된 R4는 새 검증이 필요하다.
- **V2 — 미구현·미검증 보고:** 동시 초안 편집. 새 제품 동작의 실행 결과는 없다.
- **H1 — 폐기된 가정:** 월 10건 × 9,000원 = 비용·환불 전 90,000원은 이전 유료 모델의 가정이다. 월 10건은 미검증이며 현재 매출 목표가 아니다.

## 수용 시나리오와 남은 확인

모두 **계획됨·결과 미관측**이다. 실행 시 무료 팀 버전의 환경·리비전·실행일을 기록한다.

| 대상 | 조건·행동 → 관찰할 결과 |
|---|---|
| R1 | 두 팀원이 같은 초안을 열고 순차 저장 → 첫 저장 공유, 오래된 저장 충돌 안내·미저장 내용 유지 |
| 권한 | 미가입자·제거된 멤버의 접근·저장 → 거부, 기존 기여 이력 보존 |
| R4 | 결제 이력 없이 발송·재시도 → 무료 고정 버전 하나; 실패 시 초안 보존 |
| R2 | 고객 조회·일반 팀원의 승인 시도 → 결정 없음; 지정 고객의 수락·거절 → 버전·주체·시각 기록 |
| R3 | 수락된 제안의 금액 또는 납기 변경·발송 → 새 승인 대기, 이전 수락 보존, 자동 승인 없음 |
| R2·R3 | 오래된 링크 결정, 상반된 결정, 결정·철회 경쟁 → 허용된 상태 전이 하나만 확정, 최신 상태 안내 |

후속 측정안: 동료 저장·고객 결정·후속 기회가 있는 팀의 재사용. 분모·기간·성공 기준은 미정이다. 역할·이메일 확인·충돌 해결은 추천이다. 문서만 점검했으며 제품·실험 테스트는 미실행이다.
