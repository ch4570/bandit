## 4. 바로 쓸 마케팅과 작은 검증

**조건·행동 유도**

> 직원 12명 이하 단일 카페 대상. 9/28~10/11 유료 실험, 점포당 14,500원(부가세 제외), 최대 5곳입니다. 설치 없이 시작하며 자동 갱신은 없습니다.  
> **우리 매장 인계 한 건으로 10분 시연 신청하기**

지원 시간·환불·제공 방식은 시연 신청 안내와 결제 동의서에 위 조건대로 함께 적는다. 성과 수치나 고객 추천사는 넣지 않는다.

**채널 순서:** 가온이 기존 시연 점주 3명에게 후속 제안을 준비하고, 지인의 신규 점주 5명 소개를 요청한다. 소개 가능성이 실제 접촉은 아니므로 중복 점포를 제거해 센다. 지역 커뮤니티는 운영진이 초안을 허용한 경우에만 보조 채널로 사용한다. 회원 63명을 도달 수로 세지 않는다. 직원 영상 계정은 구매자 구성이 불명확해 이번 유료 획득의 주 채널에서 제외한다.

**측정·판정—모두 제안 기준**

- **9/14~25:** 실제 제안을 받은 적격 점포 수 → 응답 수 → 시연 완료 수 → 결제 수를 가온의 점포별 표로 기록한다. 동일 제안을 최소 5곳에 전달하고 2곳 이상 결제하면 소규모 제공을 진행한다.
- 5곳 이상 제안했는데 결제 0이면 같은 제안의 모집을 중단하고 거절 이유에 따라 대상·가치를 수정한다. 1곳이면 약속대로 제공하되 확장하지 않는다. 5곳 미만 노출은 수요 부재가 아닌 모집 미완료다.
- **9/28~10/11:** 근무표에서 확인한 인계 기회를 분모로 메모·다음 교대 읽음을 각각 센다. ‘전달 사항 없음’은 별도 기록한다. 직접 알림 여부도 같은 행에 남겨 알림 없는 기회를 분리한다.
- 각 점포에 주당 최소 5기회가 있을 때, 양 주 모두 전체 기회 대비 읽음 60% 이상인 점포가 2곳 이상이고 지원이 점포당 2주 30분 이내면 다음 유료 제안을 준비한다. 이는 통계적 성공 기준이 아닌 운영 판단선이다.
- 기회 부족·로그 소실은 판정 불가, 기회가 있었는데 사용하지 않은 것은 부정적 관찰이다. 첫 가치는 ‘직원 작성→다음 교대 읽음→점주 조회’가 한 번 연결된 시점이다.

획득비는 실제 모집·소재 지출을 결제 점포 수로 나누고, 모집 노동시간은 따로 보고한다. 결제 0이면 획득비를 0으로 표시하지 않는다.

## 5. 디자이너·개발자 인계

| 화면·규칙 | 동작과 상태 |
|---|---|
| **R1 시작/접근** | 점주에게 가격·기간·방식·지원·종료 조건을 먼저 표시한다. 가온이 구매자와 점포를 확인하고 직원용 접근 경로와 점주용 접근을 분리한다. 직원 공유 접근은 개인 본인 인증이 아님을 안내한다. 유출 시 경로를 교체하고 기존 접근을 막는다. |
| **R2 인계 목록/작성** | 점포·날짜·대상 교대 → 미확인 인계 → 작성 버튼 순서. 항목은 내용·작성 교대·대상 교대·시각. 빈 화면은 ‘아직 등록된 인계 없음’이며 완료로 표시하지 않는다. 저장 중/성공/실패를 구분하고 실패 시 입력을 유지한다. |
| **R3 읽음** | 다음 교대가 내용을 보고 ‘읽었습니다’를 눌러야 표시된다. 페이지 열기만으로 바뀌지 않는다. ‘업무 완료 아님’을 버튼 가까이 둔다. 교대별 확인 시각을 남기고 반복 클릭은 중복 집계하지 않는다. |
| **R4 수정/미인계 복구** | 저장된 내용은 덮어쓰지 않고 정정 항목으로 연결한다. 정정은 새 읽음이 필요하다. 다음 교대에도 미확인이면 목록 상단에 유지하고, 현 근무자가 매장 내 기존 연락 방법으로 전달한다. 퇴근자에게 확인을 강제하지 않는다. |
| **R5 점주 확인/종료** | 날짜별 인계·읽음·미확인 표시. 점주는 조회하며 직원 대신 읽음 처리하지 않는다. 취소 항목은 사유를 남기고 숨기지 않는다. 직원 순위는 없다. 종료 시 기록 사본과 종료 상태를 제공한다. |

모바일 우선으로 충분한 글자·터치 영역, 명시적 라벨, 키보드 접근, 색에만 의존하지 않는 상태를 요구한다.

**예정 인수 확인:** 소라가 직원 2명·점주 1명에게 작성→읽음→조회 과제를 주고 ‘읽음≠완료’를 설명하게 한다. 도윤은 저장 실패 후 재시도·재접속, 중복 읽음, 정정 후 재확인, 다른 점포 접근 차단을 확인한다. 가온은 수동 제공에서도 같은 규칙과 종료·환불 절차가 가능한지 확인한다. **모두 계획이며 통과 증거는 아직 없다.**

## 6. 사업모델과 경제성

동일 타깃·제공 범위의 대안이다. 아래 월 요금은 향후 제안이며 이번 14일 결제와 구분한다.

| 모델 | 점주가 받는 것·결제 단위 | 월 점포 기여액 | 첫 달 기여액 | 5점포 월 손익 |
|---|---|---:|---:|---:|
| **A 잠정 추천** | 도입비 없이 점포당 월 29,000원. 인계·조회·지원 | 13,543원 | −3,124원 | 7,715원 |
| B | 도입비 20,000원으로 초기 설정·교육, 이후 월 19,000원으로 동일 운영 | 3,873원 | 6,546원 | −40,635원 |

기여액은 고정비 차감 전이다. 계산식은 `월가격×0.967−저장·알림 2,000−지원 0.5h×25,000`. 첫 달에는 온보딩 `40/60h×25,000`을 추가하고, B는 도입비의 수수료 차감액 19,340원을 더했다. 전체 손익은 기여액×점포 수−고정비 60,000원이다.
