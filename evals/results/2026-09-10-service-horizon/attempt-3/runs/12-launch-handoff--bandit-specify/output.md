# 마감잇 첫 유료 실험 실행·인계안
**기간: 2026년 9월 14일~10월 11일｜상태: 실행 전 제안**

**잠정 추천은 ‘점주가 교대별 읽음 상태를 확인하는 인수인계 서비스’다.** 직원은 근무 중 한 번 기록하고, 다음 교대는 읽었다고 표시한다. 점주는 나중에 인계 상태를 확인한다. 메모 기능 자체보다 이 연결에 돈을 내는지 검증한다.

모든 근거는 제공된 **합성 자료**다. 실제 시장 수요나 실험 성과로 해석하지 않는다. 별도 기존 PRD는 없으며, 아래는 창업자 기록의 제약을 유지한 신규 실행안이다. 가격·운영 규칙·판단 기준은 잠정 제안이다.

## 4. 디자이너·개발자 인계

핵심 객체는 **점포, 교대 인계, 항목, 항목 버전에 대한 읽음 기록**이다.

| 화면·행동 | 규칙과 상태·복구 |
|---|---|
| 도입 안내 | 점주에게 O1 금액·날짜·지원·종료·환불 조건과 실제 제공 방식을 표시. 동의와 입금 확인을 구분 |
| 첫 접근 | 점포명·근무 중 사용 안내·역할 표시. 직원용 접근과 점주 관리 접근 분리. 링크 소지만으로 점주 권한을 주지 않음 |
| 직원 인계함 | 날짜·교대 → 미확인 항목 → 내용 → “읽었습니다—처리 완료 아님”. 빈 화면은 “등록된 인계 없음”; 인계 완료라고 표시하지 않음 |
| 인계 작성 | 다음 교대, 내용, 저장. 고객 얼굴·연락처 입력 금지 안내. 저장 실패 시 입력을 유지하고 재시도 제공 |
| 읽음 | 페이지 열기는 읽음 아님. 명시적 행동 후 공유 저장 성공 시 시각 표시. 중복 누르기는 중복 집계하지 않음 |
| 수정·철회 | 공유된 내용은 덮어쓰지 않고 정정 버전 추가. 기존 읽음은 이전 버전에 남기고 새 내용은 재확인 필요로 표시 |
| 점주 날짜별 화면 | 인계 없음·미확인·읽음 구분. 직원 성과 점수 없음. 점주는 직원 대신 읽음 처리할 수 없음 |

직원은 해당 점포의 기록·읽음만 가능하고, 점주는 기록 열람과 접근 회수를 관리한다. 개인 계정 없이 교대·역할을 선택하는 방식은 **개인 신원 증명이 아닌 자기표시**다. 퇴사·링크 유출 시 접근 경로를 교체하고 과거 기록은 유지한다. 운영자는 문의 처리에 필요한 경우만 접근한다.

미인계는 다음 근무 시 미확인 상태로 발견하게 한다. 긴급 사안은 기존 매장 연락 절차를 이용한다. 다른 점포 접근, 만료 링크, 저장 실패는 이유와 복구 경로를 글로 표시한다. 모바일에서 읽기 쉬운 계층, 명시적 라벨, 키보드 접근, 색에 의존하지 않는 상태가 필요하다.

소라는 1주차 직원 역할 2명·점주 역할 1명의 스케치 과제를 관찰한다: 작성→읽음→정정→점주 확인. 완료 여부와 “읽음=처리 완료” 오해를 기록하며 통과했다고 미리 가정하지 않는다.

## 5. 사업모델과 예산

두 모델 모두 점주가 점포 단위로 같은 서비스에 지불한다. 획득은 직접 제안, 전달은 웹/문서와 수동 온보딩·지원이다.

| 월 단위 비교 | A: 월 29,000원 | B: 도입 29,000원 + 월 19,000원 |
|---|---:|---:|
| 반복 결제 수수료 | 957원 | 627원 |
| 반복 점포별 공헌액 | 13,543원 | 3,873원 |
| 온보딩 포함 첫 달 공헌액 | −3,124원 | 15,249원 |
| 5점포 반복 월 손익, 고정비 포함 | 7,715원 | −40,635원 |
| 5점포 첫 달 손익, 고정비 포함 | −75,618원 | 16,247원 |
| 반복 월 손익분기 점포 수 | 5곳 | 16곳 |

**A를 잠정 추천한다.** 도입 장벽은 낮지만 첫 달 손실과 매우 얇은 반복 잔여액이 약점이다. B는 온보딩을 회수하지만 반복 손익분기 16곳이 지원 한도 5곳을 넘는다.

계산 근거: `costs-and-delivery.md`. 공헌액 = 수입×0.967−저장·알림 2,000−지원 12,500. 첫 달은 온보딩 16,666.67원을 추가 차감하며 B의 도입비에도 수수료를 반영했다. 위 값은 도구 계산 결과이며 원 단위 반올림이다.

지원이 월 15/30/60분이면 A 공헌액은 **19,793/13,543/1,043원**, B는 **10,123/3,873/−8,627원**이다. 지원 증가·29,000원 거절이 반복되면 가격·제공 범위를 재설계한다. 개발·디자인 유지비, 획득비, 이탈률은 제외되어 순이익·LTV로 해석할 수 없다.

O1은 비용을 절반으로 줄인다고 가정하지 않는다. 점포당 저장 2,000원·지원 30분·온보딩 전부를 반영하면 공헌액 **−17,145원**, 5곳과 고정비 포함 **−145,726원**이다. 학습 비용이며 지속 모델이 아니다.

현금 배정은 도구 100,000, 모집 120,000, 사례비 80,000, 소재 20,000, 결제비 10,000, 돌발·환불 대비 150,000원으로 **480,000원**, 미배정 **320,000원**이다. 고정비 60,000원은 도구 예약액에 포함한다. 사례비는 구매와 연계하지 않는다. 획득비는 실제 모집·소재 지출/유료 점포로 계산하고 가온의 획득 시간은 별도 보고한다.

## 6. 종료 시 확인할 인수 기준

모두 **계획된 확인이며 실행 결과는 미관측**이다.

- 직원이 저장하면 재접속한 다음 교대와 점주에게 같은 내용이 보인다.
- 화면 열기만으로 읽음이 바뀌지 않고, 정정 후에는 재확인이 필요하다.
- 저장 실패·중복 클릭·인계 없음이 성공으로 오인되지 않는다.
- 직원 접근으로 점주 관리나 다른 점포 기록에 접근할 수 없다.
- 마지막 지원 요청까지 정해진 창구에서 처리하고 기록 전달·접근 종료가 완료된다.
- 가온은 10/11에 결제·환불·반복 사용·지원 시간을 함께 보고한다. 월 구독과 이후 운영은 인력 확보 및 새 유료 관측이 필요한 미결정 사항으로 남긴다.
