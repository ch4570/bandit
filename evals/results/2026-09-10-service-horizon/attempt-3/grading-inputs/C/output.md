# 마감잇 첫 유료 실험 실행·인계안

**잠정 추천: 메모 앱보다 ‘다음 교대의 읽음 여부를 점주가 확인하는 인수인계 서비스’를 먼저 판다.** 직원 12명 이하 단일 카페, 최대 5곳에 한정한다. 직원은 근무 중 한 번 기록하고, 다음 교대는 출근해서 읽음을 표시한다. 점주는 날짜별 미확인 기록을 본다.

아래는 모두 **실행 전 제안**이다. 자료는 합성 기록이며 실제 수요의 증거가 아니다. 준비 기간은 2026년 9월 14일~10월 11일이다.

- 아래 유료 조건을 보고 점주가 실제 결제할 것인가? 거절한다면 가격·가치·접근 중 무엇 때문인가?

답변만 모으지 않고 **같은 제안에 대한 구매 행동과 실제 교대 사용**까지 관찰한다.

## 3. 모집 문구와 작은 검증

> 마감잇에 남기고, 다음 교대는 출근해서 읽음을 표시하세요. 점주는 날짜별 확인 여부를 볼 수 있습니다. 읽음은 업무 완료를 뜻하지 않습니다.

**행동 유도**

> 우리 점포의 유료 실험 조건 확인하기

바로 아래 O1의 대상·가격·12일 일정·최대 5곳·수동 제공 가능성·지원시간·자동 갱신 없음·환불 조건을 표시한다. 시작 전 취소는 전액, 시작 후 중도 종료는 미제공 일수/12 비율로 환불한다. 핵심 흐름을 전혀 제공하지 못하면 전액 환불한다.

## 4. 소라에게 전달할 UX 요구

제안 방향은 모바일 우선, 큰 텍스트 버튼, 상태명과 시각을 함께 보여주는 방식이다. 색만으로 상태를 구분하지 않고 입력 라벨·키보드 접근·텍스트 오류를 제공한다.

| 화면·규칙 | 역할과 핵심 동작 | 예외·확인 기준 |
|---|---|---|
| R1 조건 확인·시작 | 점주가 O1 확인→적격 여부·결제 동의→가온이 결제 확인·접근 전달 | 가격·종료일·지원·환불을 동의 전에 표시. 앱 내 결제 연동은 범위 밖 |
| R2 첫 진입 | 직원용 점포 경로와 점주 관리 경로 분리. 점포명·현재 교대·“출근 후 확인” 안내 | 첫날 빈 화면은 ‘아직 기록 없음’. 다음 교대·접근 방법을 온보딩에서 정함 |
| R3 인계 작성 | 직원이 다음 교대와 내용을 입력→저장 | 저장 확인 전 성공 표시 금지. 실패 시 입력 유지·재시도. ‘전달할 내용 없음’과 미작성을 구분 |
| R4 읽음 | 다음 교대가 내용을 보고 “읽었습니다—처리 완료 아님” 선택 | 단순 열람은 읽음 아님. 중복 클릭은 한 번만 반영. 개인 신원 확인이 아닌 교대의 확인 표시 |
| R5 점주 확인·복구 | 날짜별 기록·읽음 시각·미확인 표시 | 미확인은 ‘누락 확정’으로 표현하지 않음. 점주는 현재 근무자에게 매장 안에서 확인 요청 |

직원은 점포 인계 작성·읽음만, 점주는 접근 관리와 날짜별 조회를 한다. 전달 후 정정은 원문을 보존한 새 항목으로 만들고 다시 읽음을 받는다. 접근 유출 시 가온이 경로를 교체한다. 네트워크 장애 시 기존 종이·채팅으로 인계하고 복구 후 중복 입력 여부를 확인한다.

**예정 검증 V1:** 1주 차 참여자가 설명 없이 기록→다음 교대 읽음→점주 미확인을 찾게 한다. 읽음을 처리 완료로 해석하거나 저장 실패를 성공으로 오해하면 판매 전 수정한다. 웹에서는 새로고침 후 저장 유지, 다른 점포 접근 차단, 재시도 중복 방지도 확인한다. 모두 미실행 기준이다.

## 5. 사업모델과 비용

두 모델 모두 점주가 점포 단위로 지불하고 O1의 핵심 가치와 제한 지원을 받는다. 획득·온보딩·지원은 가온, 웹 유지와 화면은 도윤·소라가 맡는다.

| 월 운영 대안 | A: 월 29,000원 | B: 도입 20,000원＋월 19,000원 |
|---|---:|---:|
| 반복 공헌이익/점포 | 13,543원 | 3,873원 |
| 5점포 반복 손익, 고정비 차감 | 7,715원 | −40,635원 |
| 5점포 첫 달 손익, 온보딩 포함 | −75,618원 | −27,268원 |
| 반복 손익분기 점포 수 | 5곳 | 16곳 |

계산식은 `월요금×0.967−저장·알림 2,000−지원 12,500`이다. 전체에서 고정비 60,000원을 뺀다. 첫 온보딩은 점포당 `40/60×25,000=16,667원`; B는 도입비 순수입 19,340원을 더했다.

**잠정 추천은 A.** B는 초기 비용을 일부 회수하지만 반복 손익분기 16곳이 지원 한도 5곳을 넘는다. A도 5곳에서 남는 돈이 작다. 지원이 월 15/30/60분이면 A 공헌이익은 19,793/13,543/1,043원으로 바뀐다. 월 19,000원만 수용되고 지원이 크게 줄지 않으면 B로 전환하기보다 제공 방식부터 바꾼다.

12일 O1은 월요금과 별개다. 비용은 보수적으로 저장·반복지원 한 달치를 적용한다. 5곳 매출 72,500원에서 수수료·변동비·지원·온보딩·고정비를 빼면 **−145,726원**이다. 학습 비용이며 수익 사업 검증이 아니다.

현금 배정은 도구 100,000, 모집 100,000, 구매와 무관한 사례비 120,000, 소재 40,000, 결제비 10,000, 점포 변동비 50,000, 환불·돌발 예비비 180,000으로 **600,000원**, 미배정 **200,000원**이다. 고정비 60,000원은 도구 예약액에 포함한다. 매출을 예산 확대 근거로 쓰지 않는다.

위 산식·합계는 이번 응답에서 JavaScript로 계산 확인했다. 장기 개발·디자인 유지비, 획득 인건비, 이탈·생애가치는 미포함이다.

**9월 14일 첫 행동:** 가온은 O1 제안서와 점포별 기록표를 준비하고, 소라는 ‘읽음≠완료’ 흐름을 먼저 확인한다. 10월 11일에는 구매·사용·지원비를 함께 판단한다. 다음 서비스 기간의 담당 시간까지 확보되기 전에는 월 구독 결제를 받지 않는다.
