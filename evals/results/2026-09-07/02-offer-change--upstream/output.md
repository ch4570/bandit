# ChangeDesk PRD v2 — 무료 견적·팀 공동 초안
날짜: 2026-09-07 · 상태: 다음 파일럿 방향 채택, 구현·검증 대기  
근거: `input/current-plan.md`, `input/observations.md`

## 1. 요약
다음 파일럿부터 견적당 9,000원 결제를 없애고 무료로 제공한다. 같은 팀 동료는 링크로 견적 초안을 함께 작성하되, 발송된 견적의 수락·거절은 지정된 고객 담당자만 할 수 있다.

추천 방향은 **무료 공동 작성 파일럿을 제한적으로 진행하며 사용 가치와 권한·버전 안전성을 검증하는 것**이다. 관측 결과만으로 전면 출시나 사업성 검증을 선언하지 않는다.

## 2. 담당자
제품·개발·분석 담당자의 이름은 제공되지 않았다. 파일럿 시작 전에 요구사항 승인, 권한·동시 편집 검증, 지표 수집 책임자를 지정한다.

## 3. 배경과 결정 기록

| ID | 원래 기록 | v2 처리 |
|---|---|---|
| D1 | 채택됨: 프리랜서가 고객 발송 전 견적당 9,000원 일회성 결제. 구독 아님 | 다음 파일럿부터 대체. 과거 유료 운영 기록은 유지 |
| H1 | 프리랜서당 월 유료 견적 10건이면 비용·환불 전 월 총매출 90,000원 가능 | 과거 가설로 보존. 월 10건 수요는 검증되지 않았고 무료 정책의 매출 근거로 사용하지 않음 |
| D2 | 신규 | 다음 파일럿은 무료이며 팀 동료의 링크 기반 공동 초안 작성 허용 |

**8월 유료 관측:** 8명이 각각 1건을 구매하고 사용했다. 최초 결제액은 72,000원, 전액 환불 2건은 18,000원, 보고 시점 남은 수납액은 54,000원이다. 환불 비율은 2/8(25%). 모두 30일 안에 후속 견적 기회가 있었고, 2/8(25%)이 재사용했다. 제안받은 전체 인원이 없어 구매 전환율은 알 수 없다.

**9월 무료 미리보기:** 가입자 24명 모두 앱을 열었고 14/24(58.3%)가 견적을 발송했다. 발송자 중 후속 기회가 확인된 6명에서는 4/6(66.7%)가 재사용했다. 나머지 발송자 8명은 경과한 10일 동안 두 번째 기회가 없었다. 미발송자 10명의 기회 여부는 미수집이므로 이들을 재사용 실패로 계산하지 않는다. 결제를 요청하지 않아 지불 의향은 알 수 없다.

가격·공동 작성·모집 경로가 동시에 바뀌었고 무작위 배정도 없었다. 30일과 10일 관측은 직접 비교할 수 없다. 이는 A/B 테스트가 아니므로 인과적 상승률, 유의성 또는 승자를 제시하지 않는다. 표본도 작고 효과 크기·검정력 설계가 없어 충분한 표본이라고 판단할 수 없다. 공동 작성은 수동 지원이었으며 제품의 동시 편집 증거가 아니다.

## 4. 목표와 성공 지표
목표는 팀이 변경 견적을 함께 준비하고, 고객이 정확한 조건에 명시적으로 결정하도록 돕는 것이다.

다음 파일럿은 참여자별 30일을 관측한다.

| 지표 | 측정 기준 |
|---|---|
| 첫 발송률 | 30일 내 1회 이상 발송한 참여자 / 전체 참여자 |
| 기회 대비 재사용률 | 첫 발송 후 후속 기회에 재사용한 사람 / 후속 기회가 확인된 발송자 |
| 공동 작성 사용 | 동료가 실제 수정한 초안 수 / 전체 초안 수 |
| 고객 결정 | 발송 버전별 조회·명시적 수락·거절을 분리 집계 |
| 안전성 | 무권한 수정·승인, 변경 유실, 이전 승인 오적용 건수 |
| 운영 부담 | 수동 지원 시간과 건당 비용 |

기회 없음과 기회 미확인을 별도 기록하고, 모든 비율에 분모와 관측 기간을 표시한다. 사용 지표의 수치 목표는 시작 전 합의할 미결정 사항이다. 안전성 문제는 출시 전 시나리오 검증에서 0건이어야 한다는 기준을 제안한다. 무료 이용은 매출·지불 의향 검증으로 취급하지 않는다.

## 5. 대상과 가치
대상은 고객의 변경 요청에 견적을 내는 프리랜서와 같은 팀 동료, 그리고 지정된 고객 담당자다. 팀은 초안 준비를 나누고 고객은 승인할 조건과 버전을 명확히 확인한다.

결제 제거와 공동 작성이 발송·재사용을 늘린다는 것은 아직 가설이다. 시장 규모나 경쟁 우위는 제공된 자료로 판단할 수 없다.

## 6. 요구사항과 흐름
흐름: 초안 생성 → 팀 동료 초대·공동 작성 → 작성자 발송 → 고객 조회 → 지정 담당자의 명시적 수락·거절.

| ID | 현재 요구사항·수용 기준 |
|---|---|
| R1 변경 | 기존 ‘작성자만 초안 수정’을 대체한다. 작성자와 초대된 같은 팀 동료가 초안을 수정한다. 고객 담당자 지정은 유지한다. 동료의 작성 권한은 고객 승인 권한을 부여하지 않는다. |
| R2 유지 | 고객 링크 조회는 조회만 기록한다. 지정된 담당자의 명시적 수락·거절만 결정으로 기록한다. 링크 소지만으로 승인할 수 없다. |
| R3 유지 | 발송 후 금액 또는 납기 변경 시 새 버전을 만든다. 이전 수락은 새 조건에 적용되지 않는다. 공동 작성도 이 규칙을 우회할 수 없다. |
| R4 대체 | 기존 결제 화면, 미결제 발송 차단, “Send your quote · KRW 9,000” 문구를 다음 파일럿에서 제거한다. 결제 없이 발송할 수 있어야 한다. |
| R5 신규 제안 | 초대 링크의 팀원 접근 확인·회수 기능을 제공한다. 발송 권한은 작성자에게 둔다. 동시 수정 충돌을 감지·안내하고 타인의 변경을 조용히 덮어쓰지 않는다. |

실시간 공동 편집 방식, 링크 인증 방식은 설계 미결정이다. 구독, 새 유료화, 승인 권한 확대는 이번 범위 밖이다.

## 7. 실험과 검증 기록
**X1 보존:** 접근 가능한 프리랜서에게 유료 견적을 제안하고 30일간 수납·전달·환불·재사용을 관측하는 원래 실험이다. 보편적 통과 기준은 채택되지 않았다. 8월 결과를 기록하되 사후 기준으로 성공 처리하지 않는다.

**X2 제안:** 무료 공동 작성의 사용성과 안전성을 30일 관측한다. 모집 경로와 수동 지원 여부를 기록한다. 협업의 인과 효과를 검증하려면 이후 가격·모집 조건을 같게 하고 팀 단위 무작위 배정을 별도로 설계한다.

| 기록 | 기존 증거와 현재 효력 |
|---|---|
| V1 | 2026-08-10 v1 스테이징 명시적 수락·거절 전이 통과, R2/R3 연결. 새 권한·협업 흐름의 통과 증거는 아님 |
| V2 | 같은 날 v1 미결제 발송 차단 통과. 역사적 기록이며 R4 대체로 현재 수용 기준에서는 제외 |
| V3 | 동시 초안 편집 미구현·미검증. 수동 미리보기로 검증 완료 처리하지 않음 |

## 8. 출시와 미결정 사항
파일럿 전에 담당자, 사용 지표 목표, 인증·충돌 처리 방식을 확정한다. 이후 무료 발송, 팀원 접근·회수, 동시 수정·발송 충돌, 무권한 승인 차단, R2/R3 회귀 검증을 수행한다. 모두 **예정된 검증이며 새 실행 결과는 없다**.

검증 후 제한된 파일럿을 시작하고 참여자별 30일 관측을 마친 뒤 확대 여부를 결정한다. 일정·개발 비용은 미정이다. 승인 오류나 변경 유실이 발견되면 확대를 중단하고 수정·재검증한다.
