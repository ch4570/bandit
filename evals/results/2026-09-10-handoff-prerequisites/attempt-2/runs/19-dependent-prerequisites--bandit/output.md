# ‘맞은편’ 4주 파일럿 명세

**기간:** 2026년 10월 5일~11월 1일, 모든 시각은 한국시간.  
**권고안:** 기존 도구로 제공하는 수작업 서비스로 시작한다. 이미 수락한 무료 **8묶음**을 우선 이행하고, 지원 일정과 전달 방식이 확인되면 동아리 밖 성인 배우에게 **개인 유료 2묶음**을 추가 제공한다. 앱 개발과 월 구독은 보류한다.

이 문서는 실행 전 기획안이다. F4의 기존 수락사항은 유지하며, 아래 추가 운영조건·가격·목표는 제안이다. 자료는 모두 합성 사례이며 실제 수요나 성능의 증거가 아니다.

## 1. 근거와 선택

| 근거 | 제품·사업 결정 | 한계와 다음 확인 |
|---|---|---|

| F2 배우-C, F3-C: 대본 변경과 버전 혼동 | 제작 전 버전 확정, 결과물에 역할·버전 표시 | 내용·역할 변경은 새 묶음으로 산정 |

| F2 진행자-F/G | 운영진 전달 채널과 향후 단체 구매 탐색 | 예산 승인·게시·추천 인원 모두 미확정 |

| F4-A/B | 무료 4명에게 각 2회, 총 8묶음 우선 | 신규 모집 중단과 기존 의무 종료는 별개 |

**우선 대상:** 현재 연습 중인 짧은 장면이 있고, 혼자 상대역을 들으며 반복 연습하려는 성인 배우. 휴식중-H처럼 복귀나 일정 조율이 주된 문제인 사람은 이번 대상에서 제외한다.

**대안 비교**

- 자기 녹음은 무료이고 즉시 가능하지만 역할별 편집·정지를 본인이 맡는다. 맞은편은 이를 대신 준비하는 서비스다.
- 동료 상대역은 반응을 주고받을 수 있지만 시간을 맞춰야 한다. 맞은편은 실시간 반응을 제공하지 않는다.
- 인쇄물만 제공하면 제작 부담은 낮아지지만 ‘상대역을 듣는 연습’ 가설을 확인할 수 없다.
- **개인 단건 구매를 선택한다.** 사용자와 구매자가 같아 가격 반응을 해석하기 쉽다. 동아리 일괄 구매는 여러 승인자와 역할별 제작비가 필요하므로 후속안으로 둔다.

## 2. 단일 제공안

**한 묶음:** 배우 1명 × 대본 버전 1개 × 역할 1개 × 쉼 종류 1개.

- 입력 한도는 **2쪽 이하, 상대역 대사 24개 이하, 상대역 음성 합계 3분 이하를 모두 충족**해야 한다.
- 결과물: 상대역 음성·자기 차례 쉼이 포함된 음성 파일 1개와 큰 글자 대사표 PDF 1개.
- 같은 대본·역할의 쉼 또는 읽기 오류 수정 1회 포함.
- 대본 내용·역할 변경은 새 묶음이다. 기존 주문을 자동 변경하거나 추가 과금하지 않는다.
- 작품 전체, 무제한 수정, 두 쉼 버전 동시 제작, 연기 지도, 실시간 상대역, 영상 제작, 자동 음성 생성은 제외한다.
- 연기력·공연 성과 향상을 홍보 문구로 약속하지 않는다.

신규 개인 가격은 **묶음당 총 12,000원**으로 시험한다. F2-B의 발언 범위에 근거한 가설이며, 수익성 검증 가격은 아니다. 기존 8묶음은 무료 그대로 유지한다.

## 4. 납기와 의존 작업

### 기존 약속

별무리 별-1/2, 느린막 막-1/2에게 각각 다음을 제공한다.

| 회차 | 약속된 입력 | 최초 전달 |
|---|---|---|
| 1회 | 10/6 화 12시 | 10/8 목 22시까지 |
| 2회 | 10/20 화 12시 | 10/22 목 22시까지 |

소리의 작업 가능 시간은 매주 **화·목 19~22시**뿐이다. 정상 입력은 화요일 제작하고 도담이 수요일 대조하여 목요일을 보완 여유로 남긴다.

**초기 입력 누락·지연:** 도담이 화요일 15시까지 누락 항목을 알린다. 참여자가 보완할 수 있는 시간을 확인하고, 목요일 17시까지 완전한 입력이 도착하면 도담이 19시 전 검수하여 당일 제작에 넘긴다.

최대 4묶음이 모두 늦어도 목요일 작업은 `4×35+공통 20=160분`이다. 19~21:40 제작하면서 도담이 완성 순서대로 40분간 검수하고, 22시까지 전달한다. 이는 정상 경로의 같은 4묶음을 옮긴 것이며 추가 4묶음이 아니다. 당일 결과를 받은 뒤 요청하는 수정은 다음 제작창에서 처리한다.

목요일 17시 이후 도착하거나 한도를 넘으면 기존 납기를 자동 보장할 수 없다. 도담이 영향과 가능한 다음 제작일을 개별 안내하고 조정한다. 늦은 입력을 이유로 기존 참여권을 일방 취소하지 않는다.

### 결과 전달 후 수정

- 첫 회차: 10/8 전달 → 10/12 18시까지 요청을 모으는 안 → 10/13 제작 → 10/14 전달.
- 둘째 회차: 10/22 전달 → 10/26 18시까지 요청을 모으는 안 → 10/27 제작 → 10/28 전달.
- 신규 유료 2묶음: 10/13 12시 완전 입력 → 10/13 제작 → 10/14 18시 전달 → 10/15 12시까지 수정 요청 → 당일 제작·전달. 이 확인 시간을 사용할 수 있는 신청자만 해당 일정에 접수한다.

**종료 주 보완안:** 10/28 수정본을 받은 기존 참여자가 10/29 12시까지 오류를 알리면 소리가 19시부터 최대 4건×10분을 처리하고 도담이 검수해 20시까지 전달한다. 참여자가 20:30까지 확인할 수 있는 경우, 추가 제작자 오류 최대 4건을 40분간 보완하고 도담의 20분 검수를 거쳐 22시까지 전달한다. 이는 반복 오류 비상 여유이며 무제한 처리 보장이 아니다.

마지막 일반 문의는 10/30 12시 접수, 도담이 당일 18시 답변, 10/31 12시까지 후속 질문을 받아 18시 답변하는 안이다.

**중요한 미확정:** F4는 수정권 만료를 정하지 않았다. 위 요청 시각은 기존 권리를 줄이는 확정조건이 아니다. 도담은 10/5부터 참여자의 확인 가능 시간과 종료안을 협의해야 한다. 늦은 요청·반복 오류로 10/29 이후 음성 작업이 필요하면 다음 달 소리의 참여를 추정하지 말고, 담당·일정·비용을 별도로 확보해야 한다. 합의가 없으면 지원 종료로 표시하지 않으며 신규 판매를 보류한다.

## 5. 주간 수량·시간·현금

다음은 정상 이행 계획이다. 수정 시간을 실제 처리 주에 배치했다.

| 주 | 신규 제작 | 도담 예약 | 소리 예약 |
|---|---:|---:|---:|
| 10/5~11 | 기존 무료 4 | 360분 | 160분 |
| 10/12~18 | 조건부 유료 2 | 320분 | 150분 |
| 10/19~25 | 기존 무료 4 | 300분 | 160분 |
| 10/26~11/1 | 없음, 수정·종료 | 240분 | 60분 |

도담 시간에는 공통 준비 주 40분과 별도 운영 각각 180/180/120/180분을 포함했다. 별도 운영으로 안내, 최대 신규 신청 6건의 상담·탈락 안내, 모집 준비, 이용 확인, 결제 관리, 회고·삭제를 처리한다. 초과 신청은 대기 안내만 하고 추가 제작을 약속하지 않는다.

각 주 상한은 도담 480분, 소리 360분이다. 남는 시간은 오류·지연 여유이며 판매 수량으로 전환하지 않는다. 특히 마지막 주는 종료 지원용으로 남긴다.

**현금 배정:** 소리 협업비 160,000원 + 도구 40,000원 = 확정 200,000원. 나머지 100,000원은 예비비이며 광고비는 0원이다. 수입이 발생해도 지출 상한 300,000원은 유지한다.

**계산 확인:** 제공된 제품 코드·테스트는 실행하지 않고 독립 산술 계산만 수행했다. 반환값은 총 10묶음, 도담 1,220분, 소리 530분, 늦은 입력 최대 제작 160분, 묶음당 직접 노동비 25,000원이다.

## 6. 모집부터 수정까지의 경험

**모집 문구 초안**

> 혼자 연습할 때, 상대역 대사를 들으며 내 차례를 연습하세요.  
> 성인 생활연극 배우를 위한 작은 장면 음성 파일과 큰 글자 대사표를 준비합니다. 배우 1명·역할 1개 기준 12,000원, 이번 신규 유료 모집은 최대 2묶음입니다. 2쪽·상대역 24대사·음성 3분 이내이며 같은 대본·역할의 수정 1회가 포함됩니다. 10/13 정오까지 입력 확인 후 10/14 전달하는 일정입니다.  
> **[조건 확인 후 신청하기]** — 신청만으로 제작이나 결제가 확정되지는 않습니다.

도담은 10/9~12에 허용된 개인 소개 경로로 동아리 밖 배우를 모집하는 안을 준비한다. 별무리의 공지 전달은 첫 사용 후 결정 사항이고, 느린막의 10/12 이후 검토는 게시 승인이 아니다. 두 채널에 모집 수량을 의존하지 않는다. 허용된 경로가 확보되지 않으면 유료 실험은 미실행으로 남긴다. 유료 광고는 도달·전환 근거가 없고 운영 부담이 커 보류한다.

**화면·문서 순서와 상태**

1. **안내:** 혜택 → 샘플 → 입력 한도 → 가격·납기·수정 조건 → 신청. 예시는 합성 대본만 사용한다.
2. **신청:** 연락 경로, 성인 여부, 역할·버전·쉼, 권한 확인, 텍스트 입력. 누락 항목을 글자로 표시하고 보완 방법을 제공한다.
3. **확정:** 도담이 묶음 ID에 참여자·버전·가격·납기·지원조건을 연결한다. 동일 신청은 중복 예약하지 않는다. 신규는 조건 수락 후 제작 전 결제하며, 실제 수납 방식·수수료·환불 절차 확인이 선행조건이다.
4. **대기·전달:** ‘보완 필요/검수 완료/제작 중/전달 완료’를 안내한다. 파일명과 PDF에 역할·버전·쉼을 표시한다. 링크 실패는 본인 확인 후 대체 경로로 재전달한다.
5. **연습·수정:** 내려받기, 인쇄, 문제 신고, 수정본 받기를 명확히 구분한다. 수정본에는 개정 표시를 하고 구본 혼용을 안내한다.

제안 환불안은 제작 전 취소 및 제공자 사정으로 납기 이행이 불가능할 때 전액 환불이다. 제작 후 단순 변심 조건과 법정 의무는 수납 전 확인한다. 제작자 오류의 재발은 유료 새 묶음으로 취급하지 않는다.

모바일에서는 큰 글자·명확한 항목명·키보드 접근·색상 외 오류 설명을 사용한다. 화면 잠금 재생은 아직 검증되지 않았으므로 광고에 보장하지 않는다.

## 7. 정보·권한·종료

동아리 구매자라도 다른 배우의 파일 열람권을 얻지 않는다. 도담·소리는 제작에 필요한 범위만 접근하고 참여자는 본인 결과물만 받는다. 전달 링크를 가졌다는 이유만으로 권한을 인정하지 않는다.

느린막의 원본·작업본·공유본은 **11/8까지 삭제**해야 한다. 운영 인력이 확보된 11/1에 삭제하는 것을 기본안으로 하고, 남은 지원이 있으면 삭제기한과 함께 해결한다. 다른 참여자에게도 같은 보관정책을 제안한다. 개인 기기에 내려받은 사본까지 원격 삭제된다고 설명하지 않는다. 회고에는 대사·음성 없이 집계만 남긴다. 홍보 재사용은 별도 동의 없이는 금지한다.

## 8. 사업성·검증·후속 결정

직접 노동비는 `도담 40분×15,000원/시간 + 소리 45분×20,000원/시간 = 25,000원/묶음`이다.

| 단가 가정 | 직접 노동비 차감액 |
|---:|---:|
| 8,000원 | −17,000원 |
| 12,000원 | −13,000원 |
