# 마감잇 첫 유료 실험 실행·인계안

**잠정 추천: 직원 12명 이하 단일 카페에 ‘근무 중 기록하고 다음 교대가 읽음을 남기며 점주가 확인하는 서비스’를 점포당 월 29,000원으로 제안한다.** 직원용 메모 앱보다 점주가 인계 상태를 확인할 수 있는 최소 서비스를 만든다. 최대 5점포이며 자동 갱신은 하지 않는다.

준비 기간은 **2026년 9월 14일~10월 11일**이다. 첫 유료 제공 후보 기간은 **10월 12일~11월 11일**이지만, 해당 기간의 인력·도구 제공을 확인하기 전에는 결제나 확정 예약을 받지 않는다.

아래 가격·일정·판정 기준·세부 정책은 제안이다. 인력·예산·제외 기능은 창업자 기록의 제약을 따른다. 모든 고객 기록과 비용 입력은 합성이며 실제 시장 검증 결과가 아니다.

- 점주에게 날짜별 읽음 확인만 제공해도 월 29,000원을 낼 이유가 있는가?

답은 인터뷰 의견과 실제 구매 행동을 분리해 기록한다.

## 4. UX·제품 규칙

**역할:** 점주는 구매·직원 접근 관리·날짜별 조회를 한다. 직원은 자기 점포에서 작성하고 읽음을 남긴다. 가온은 온보딩·문의 해결에 필요한 범위로만 접근한다.

**접근 제안:** 점주 접근과 직원 접근을 분리하고 직원별 취소 가능한 초대 경로를 제공한다. 개인 계정 설치는 요구하지 않는다. 읽음의 이름은 초대 대상 기준이며 본인 인증된 근태 증거가 아니다. 퇴사자 접근 취소 후에도 과거 기록은 유지한다.

**핵심 객체:** 점포, 접근 권한, 인계 항목, 항목 버전, 읽음 기록, 유료 제공 동의. 읽음은 해당 버전에 대한 확인이며 처리 완료가 아니다.

| 화면 | 내용 순서·주요 행동·상태 |
|---|---|
| 신청·조건 확인 | 대상 → 포함/제외 → 월 가격·기간·지원·환불 → 조건부 신청. 정원 초과 시 대기, 결제 없음 |
| 첫 직원 진입 | 점포·이름 확인 → “근무 중만 사용, 읽음≠완료” → 오늘 인계. 빈 상태는 “아직 인계가 없습니다”, 작성 버튼 |
| 인계 목록·작성 | 날짜 → 인계 내용 → 작성자·시각 → 읽음 상태. 작성 저장 실패는 입력 유지·재시도, 저장 성공과 구분 |
| 다음 교대 확인 | 항목 내용 → “읽었습니다” 버튼. 조회만으로 읽음 처리하지 않음. 반복 누름은 중복 집계하지 않음 |
| 점주 날짜별 조회 | 인계 없음/읽음 없음/읽음 있음 구분. 개인 순위 없음. 미확인은 다음 근무 중 점포 내부 전달로 해결 |

작성자는 내용을 수정할 수 있으나 새 버전을 만들고 재확인 대상으로 표시한다. 이전 읽음은 이전 버전에 남는다. 오래된 화면에서 읽음을 누르면 최신 내용을 보여주고 다시 확인받는다.

만료·취소된 접근은 기록을 노출하지 않고 점주에게 새 접근을 요청하도록 안내한다. 퇴근 후 독촉 알림은 보내지 않는다. 모바일 한 열 구성, 큰 터치 영역, 명시적 레이블, 키보드 조작, 색상에 의존하지 않는 상태·오류를 적용한다.

소라는 직원에게 “우유 재고 인계를 남기고 다음 교대로 읽기”, 점주에게 “어제 미확인 인계 찾기”를 요청한다. 도움 없이 완료했는지와 읽음을 완료로 오해했는지 관찰한다. 반복 오해가 있으면 모집 전에 문구·버튼을 수정한다.

## 5. 사업모델과 돈이 남는 범위

`costs-and-delivery.md`의 동일한 부가세 제외 원화 기준을 사용한다. 월 반복 변동비는 저장·알림 2,000원, 지원 인건비 12,500원, 결제액의 3.3%다. 온보딩 인건비는 최초 16,667원이다.

| 모델 | 점주가 받는 것·결제 | 반복 월 점포당 잔여액 | 5점포 반복 월, 고정비 차감 후 | 첫 달 5점포, 온보딩·고정비 차감 후 |
|---|---|---:|---:|---:|
| **A 잠정 추천** | 동일 서비스, 월 29,000원 선결제 | 13,543원 | 7,715원 | −75,618원 |
| B | 동일 서비스, 최초 도입비 30,000원＋월 19,000원 | 3,873원 | −40,635원 | 21,082원 |

A는 낮은 초기 구매 부담과 단순한 제안을 택하지만 첫 달 적자다. B는 첫 달 온보딩을 회수하지만 반복 운영은 현재 5점포 한도에서 적자다. 반복 손익분기점은 A 5점포, B 16점포로 후자는 지원 한도를 넘는다.

**계산 검증:** 실제 계산 도구 반환값으로 대조했다. 반복 잔여액=`가격×0.967−2,000−12,500`; 전체=`점포당 잔여액×5−60,000`; 첫 달에는 온보딩 비용을 추가하고 B는 도입비 순수입 29,010원을 더했다. 원 단위 반올림이다.

이 수치는 획득비·장기 개발·디자인 유지비 이전의 잔여액으로 완전한 이익이 아니다. 지원 시간이 30분보다 늘면 A의 여유도 빠르게 사라진다. 실제 시간 계측에서 반복 적자가 예상되면 가격 인상·지원 범위 축소를 다음 계약부터 재설계한다. B로 바꾸려면 낮은 월 가격의 구매 개선과 반복 적자 해소를 함께 확인해야 한다.

**4주 현금 배분:** 도구 예약 100,000원, 모집 120,000원, 사례비 80,000원, 소재 30,000원, 결제비 예약 10,000원, 돌발 운영 160,000원, 미배정 300,000원＝**800,000원**. 월 도구비 60,000원은 도구 예약액 안에서 지출하며 중복 가산하지 않는다. 사례비는 구매와 무관하게 지급한다. 획득비는 실제 모집 현금과 모집 노동 환산액을 각각 동일한 실제 유료 점포 수로 나누며, 유료 0이면 산출하지 않는다.

## 6. 제공 약속과 최종 인수 기준

현재 확정된 인력은 10월 11일까지다. 가온은 10월 4일까지 **10월 12일~11월 11일 제공 및 11월 13일 문의 마감 대응** 자원을 확인해야 한다. 미확정이면 일정·결제를 연기한다.

제안 지원 창은 월·수·금 18~19시 KST, 다음 지원 창까지 첫 답변이다. 최대 5점포의 온보딩 200분은 10월 12~14일 별도 4시간에 예약한다. 접근 정보는 각 예약 전 지원 창까지 받고, 누락 시 결제·시작을 함께 미룬다. 늦은 신규 시작은 받지 않는다. 직원 참여는 실제 근무 시간에 맞춘다.

마지막 문의는 11월 11일 18시까지, 첫 답변은 당일 창, 추가 확인은 11월 13일 18시까지 받아 당일 창에서 마무리한다. 창별 처리량과 잔여 문의를 확인해 초과 시 가온이 대체 대응 시간을 확보하거나 직접 종료·환불을 안내한다. 신규 모집 중단만으로 기존 의무를 끝내지 않는다.

제안 환불은 시작 전 전액, 시작 후 고객 요청 또는 제공 불능 시 미제공 일수 비례다. 갱신하지 않아도 기간 내 지원은 유지한다. 종료 시 점주에게 기록 사본을 제공하고 접근을 종료하며 보관·삭제 일정은 결제 전 명시한다.

**아래 검증은 모두 미실행·계획 상태다.**

- 직원이 조회만 하면 읽음이 생기지 않고, 명시적으로 누르면 재접속 후에도 한 번만 표시된다.
- 항목 수정 후 과거 읽음이 새 내용의 확인으로 표시되지 않는다.
- 다른 점포·취소된 접근은 기록을 볼 수 없다.
- 저장 실패·인계 없음·미확인이 서로 다른 상태로 보이고 복구 행동이 제공된다.
- 점주가 가격·기간·지원·환불 조건에 동의하기 전에는 결제하지 않는다.
- 지원 자원 미확정 또는 정원 초과 시 유료 확정을 차단한다.

남은 핵심 결정은 **후속 지원 자원, 실제 결제 수단·환불 처리 조건, 보관·삭제 기간**이다. 가온이 결제 개방 전에 확정한다. 문서의 연결성과 계산은 확인했으며 고객 연락, 게시, 제품 실행·테스트, 파일 변경은 하지 않았다.
