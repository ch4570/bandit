**사진 한칸 — 첫 유료 운영 제안 v1**

**권고: 기존 무료 2명의 약속을 먼저 확보하고, 유료는 10월 10일 1명·총 59,000원으로 시험한다.** 10월 12일에는 추가 접수 여부를 판단하되, 이미 받은 고객의 지원은 약속한 종료일까지 이행한다. 아래 가격·결제·취소·접수 조건은 제안이며, 아직 확정된 고객 조건이 아니다.

**1. 근거와 확인할 질문**

모든 자료는 합성 사례다. 실제 시장 수요가 검증된 것으로 해석하지 않는다.

초기 대상은 **사진을 찾기 어렵고, 본인이 직접 눌러 배우기를 원하는 동네 중장년층**이다. 가족 도움, 무료 강좌, 혼자 찾기는 비교할 대안이지만 이용 경험·가격·효과는 확인되지 않았다. 운영자는 자발적 문의자에게 현재 대안, 가장 최근의 어려움, 가족의 결제 관여 여부를 묻는다. 지인 중심 4명 인터뷰로 문제의 보편성이나 지불 의사를 추정하지 않는다.

**2. 약속과 접수 조건**

유료 제안 D1은 다음과 같다.

- **10/10 토요일 60분 만남 1회**, 첫날 포함 **10/23까지 14일**.
- 전화 도움 최대 2회, 회당 15분. 예약형이며 즉시 응답 서비스가 아니다.
- 고객이 사진을 직접 찾고 정리한다. 사진 복사·보관, 수리, 기기 이전은 제외한다. 삭제 대상도 고객이 선택한다.
- 총액 **59,000원**, 자동 갱신 없는 1회 패키지. 만남 시작 전 현금 또는 계좌이체로 결제하며 운영자가 수령을 확인한다.
- 이번 시험은 시작 전 취소·불참, 기간 중 고객의 중단 요청 또는 운영자의 미이행에 **전액 환불**을 제안한다. 요청 후 3영업일 이내 처리하고, 완료 전까지 받은 돈 전액을 보유한다.
- 1명만 신청해도 진행한다. 모집 성과 미달은 기존 예약을 취소할 이유가 아니다.

월 구독은 반복 수요가 없고 다음 달 운영도 미정이므로 보류한다. 무료 참여 확대보다 동일한 조건의 실제 결제 1건이 이번 가격 가설을 더 잘 확인한다.

**먼저 해결할 기존 의무:** 무료 2명은 10/4 방문·10/17까지 전화 도움을 이미 안내받았다. 10/16 첫 전화 요청도 유지한다. 그런데 10/17은 토요일이고 전화 업무 가능 시간은 평일뿐이다.

운영자는 9/29까지 두 사람에게 개별 확인한다. 가능한 조정안은 **10/17까지 요청을 받고, 늦게 접수된 첫 전화는 10/19, 남은 두 번째 전화는 10/20까지 제공하도록 지원을 연장**하는 것이다. 이는 동의가 필요한 제안이며 기존 권리를 자동 변경하지 않는다. 동의가 없으면 원래 조건을 이행할 자원을 확보해야 한다. 현재 그런 자원은 확인되지 않았으므로, 해결 전에는 유료 예약을 확정하지 않는다. 추가 접수 중단만으로 이 의무가 사라지지 않는다.

유료 고객에게는 실제 가능한 평일 전화 시간을 결제 전에 제시한다. 10/23 마지막 요청도 같은 날 처리할 수 있도록, 예를 들어 18시 접수 마감·18~19시 지원 창구를 확보한다. 그 시간의 운영자 가용성이 확인되지 않으면 해당 조건으로 접수하지 않는다.

**3. 이번 주 홍보와 신청 실험**

준비 주간은 자료 기준 **9/26~10/2**로 잡는다. 모든 실행 담당은 운영자다.

- 9/28: 허가받은 아파트 게시판 1곳에 안내지 게시. 인쇄비 상한 8,000원.
- 9/29까지: 기존 고객 지원 조정, 대여 33,000원 조건, 현장·전화 시간 확인.
- 개인 동네 모임 계정에는 같은 조건의 소개 글 1회 게시. 주민 연락처 수집이나 단체 문자는 하지 않는다.
- 게시판은 10/10까지 유지한다. 정원 마감 시 신청 화면을 마감 상태로 바꾸고 안내도 수정한다.
- 조건 미확정 중에는 “일정 문의”만 받으며 예약 확정이나 결제를 받지 않는다.

게시판과 계정용 문안:

> **찾고 싶은 사진, 내 손으로 찾아보세요.**  
> 사진 한칸은 본인 휴대폰으로 배우는 60분 만남과 14일 동안의 전화 도움 최대 2회·회당 15분을 제공합니다. 사진을 복사하거나 보관하지 않습니다.  
> 첫 유료 운영: 10월 10일 토요일, 1명, 총 59,000원. 전화 지원은 10월 23일까지 예약제로 진행합니다. 수리·기기 이전은 포함하지 않습니다.  
> **[내용과 가능한 시간 확인하기]**  
> 신청만으로 예약·결제가 확정되지는 않습니다.

연결 화면에 전체 취소 조건을 표시한다. 연락 수단은 실제 수신·응답이 가능한 번호를 확인한 뒤 넣는다.

무료 참여자도 성과 기록에는 포함하되, 유료 전환율의 분모·분자와 섞지 않는다. 운영자는 채널, 문의일, 일정 적합 여부, 총액 전달, 신청, 예약, 결제, 환불, 소요시간을 간단히 기록한다. 게시판 노출 수는 알 수 없으므로 조회 대비 전환율을 만들지 않는다.

**4. 모바일 신청 화면 — 디자이너 전달 내용**

D1을 화면·예약 안내·결제 안내의 공통 기준으로 사용한다. 예약 시스템은 미정이며 이번에는 수동 확인을 전제로 한다.

화면 순서는 다음과 같다.

1. **무엇을 배우는지 → 10/10 날짜와 시간 → 총액 59,000원**.
2. 만남·전화 횟수, 종료일, 예약형 전화 운영시간.
3. 사진 비보관·직접 삭제 선택·제외 서비스.
4. 이름, 연락처, 기종, 가장 어려운 일, 가능한 연락시간. 가족 결제 여부는 선택 입력.
5. 취소·환불 조건과 개인정보 이용 목적 확인.
6. **“예약 확인 요청”** 버튼.

제안하는 시각 방향은 큰 본문, 충분한 대비, 넓은 버튼이다. 입력란에는 항상 이름표를 붙이고 오류를 글로 설명한다. 사진 업로드와 계정 가입은 요구하지 않는다.

신청 후에는 “요청을 받았습니다. 아직 예약 확정 전입니다”와 운영자의 다음 응답 시점을 표시한다. 운영자가 일정·지원 조건을 확인해 안내하고 고객이 수락하면 예약 확정으로 바뀐다. 가족 확인 중이면 미확정 상태를 유지하고, 응답하지 않았다는 이유로 결제로 간주하지 않는다. 가격이나 날짜가 바뀌면 다시 수락받는다.

필요 상태는 **미입력, 전송 중, 접수 완료·확인 대기, 예약 확정, 정원 마감, 전송 실패·재시도, 취소 접수·환불 완료**다. 중복 신청은 운영자가 같은 연락처를 확인해 정원을 중복 차감하지 않는다.

디자이너의 검증 과제는 “총액·날짜·전화 종료일을 찾아 설명하고, 신청이 곧 확정인지 판단한 뒤 취소 경로를 찾기”다. 아직 실시하지 않은 확인 과제다.

**5. 돈과 시간**

E3 기준으로 대관료는 이미 지출한 **110,000원 전액**을 비용에 포함한다. 단기 화면 대여는 10/4~17 **33,000원**, 10/18 오전 10시 반납 조건이다. 10/10 현장에서 사용하고 전화 지원에는 필요하지 않다는 운영 가정이다.

무료 2명까지 포함한 기본비는 다음과 같다.

`110,000 + 33,000 + 8,000 + 6,000×2 = 163,000원`

유료 인원 n의 총비용은 `163,000 + 6,000n`이다.

| 유료 인원 | 총비용 | 39,000원 가격 수지 | 59,000원 가격 수지 | 79,000원 가격 수지 |
|---|---:|---:|---:|---:|
| 0명 | 163,000원 | −163,000원 | −163,000원 | −163,000원 |
| 1명 | 169,000원 | −130,000원 | −110,000원 | −90,000원 |
| 2명 | 175,000원 | −97,000원 | −57,000원 | −17,000원 |

수지는 전원 제공 완료·환불 없음 기준의 **매출−명시된 현금비용**이다. 노동 보상과 미확인 비용은 포함하지 않았다. 59,000원에서 1명당 공헌이익은 53,000원이지만 첫 운영 전체는 적자다. 같은 기본비 가정의 손익분기 인원은 가격순 5명·4명·3명으로, 권고 접수 규모를 넘는다.

30만원은 **지출 169,000원＋예비비 50,000원＋미배정 81,000원**으로 나눈다. 고객 결제금은 별도로 환불 가능액 전액을 보유한다.

문자 도구를 추가하면 최소 계약 1·2·3개월의 총비용은 각각 213,000·257,000·301,000원이다. 최소기간 확인 전 가입하지 않는다. 수동 연락의 비용·조건도 확인 대상이며 무료라고 가정하지 않는다. 30일 화면 대여는 단기안보다 33,000원 비싸다.

전화 예약분은 요청 시점 불확실성에 대비한 중복 여유이며 실제 허용 횟수를 늘린 계산이 아니다. 두 시간대는 전용하지 않는다. 대여 반납은 10/18 현장 시간 안에서 이동 포함 소요를 확인한다.

유료 2명으로 늘리면 10/5 주 평일 배정이 준비 추가만으로 180분이 되어 추가 문의 여유가 사라진다. 따라서 빈 현장 시간만 보고 증원하지 않는다. 기본 실제 노동 추정은 11.5시간, 중복 전화 여유를 포함한 배정은 14시간이며 반납 이동은 추가 측정한다. 시간당 목표 보상은 미정이다.

계산은 별도 산술 도구 호출로 확인했다. 제품 코드·테스트는 실행하지 않았다.

**6. 10/12 판단과 종료**

아래는 관측 결과가 아닌 제안 기준이다.

- **제한적 계속 검토:** 유료 1명이 59,000원을 결제·참여하고, 배운 사진 찾기 작업을 직접 수행하며, 다른 적격 문의가 1건 이상 있다. 각 업무군이 주별 한도 안이고 기존 지원 의무가 해결돼 있어야 한다.
- **수정:** 적격 문의는 있으나 가격·토요일 일정·가족 확인이 걸림돌이면 원인을 기록하고 다음 제안에서 한 조건씩 바꾼다.
- **접수 중단:** 지원 미이행, 시간 초과, 환불 재원 부족이 발생하면 신규 확정을 멈춘다.
- **판단 유보:** 문의 자체가 적어 제안을 검토할 기회가 없었다면 수요 부재로 단정하지 않는다. 결제율은 ‘동일 총액·날짜를 전달받고 답할 기회가 있었던 적격 문의자’ 대비 결제자 수로 기록한다.

10/12에는 유료 서비스가 끝나지 않았으므로 지속 이용이나 최종 수익성이 검증되지 않는다. 새 시작일의 14일 지원·자원·시간표가 확보될 때만 추가 예약을 확정한다.

접는 경우 운영자가 홍보와 신규 신청을 닫고, 미확정 신청자에게 종료를 알린다. 무료 고객은 기존 약속 또는 개별 합의한 연장일까지, 유료 고객은 10/23까지 지원한다. 이행 불가 고객에게 직접 설명하고 합의 가능한 회복안을 제시하며 유료 환불을 처리한다. 화면은 10/18 반납하고, 마지막 지원·환불 완료 후 장부와 연락정보를 정리한다. 대관료는 환급되지 않는다.
