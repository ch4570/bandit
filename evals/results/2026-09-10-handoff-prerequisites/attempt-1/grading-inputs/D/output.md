## 3. 마케팅과 작은 검증 실험

**소개 문구**

> 마감잇은 출근 중 기록하고 읽음을 남기는 인계 서비스입니다. 직원 12명 이하 단일 카페 대상, 9/28~10/11 14일 이용료 29,000원. 온보딩·정해진 시간의 지원 포함, 자동 갱신 없음. 읽음은 업무 완료를 뜻하지 않습니다. 최대 5곳.

**행동 유도:** “우리 매장 참여 조건과 제공 방식 확인하기”

누락 감소, 시간 절약 수치, 고객 추천 문구는 쓰지 않는다. 공개용 최종 결제액과 결제 수단은 가온이 9/24까지 확인해야 하며, 원가표의 부가세 제외 기준을 고객의 최종 청구액으로 오인시키지 않는다.

9/14~27 모집, 9/28~10/11 관찰한다. 가온의 점포별 집계표에 다음을 남긴다.

## 4. 디자인·제품 요구사항

모바일 우선으로 다음 순서를 설계한다.

1. **점주 신청:** 대상·기간·가격·수동 제공 가능성·지원·환불 → 적격성·일정 → 조건 동의 → 결제 확인. 실패 시 미결제로 표시하고 중복 청구 없이 재확인한다.
2. **첫 직원 진입:** 점포명 → “읽음 ≠ 업무 완료” → 예시 한 건 → 오늘 인계. 빈 화면에는 “아직 남긴 인계가 없습니다”와 작성 버튼을 둔다.
3. **작성:** 다음 교대·내용 → 저장. 저장 중·실패·재시도를 구분하고 입력을 보존한다. 성공은 저장된 항목이 다시 조회될 때 표시한다.
4. **다음 교대:** 미확인 인계 → 상세 → “읽었습니다”. 반복 누름은 중복 확인을 만들지 않는다.
5. **점주 조회:** 날짜 → 메모 있음/없음 → 읽음/미확인. 개인 순위와 업무 완료 해석은 제공하지 않는다.

핵심 객체는 점포, 인계 기회, 메모 버전, 교대 확인이다. 직원 접근자는 해당 점포에 작성·읽음 표시할 수 있고, 점주 전용 접근자는 이력 조회와 접근 회수를 할 수 있다. 공유 직원 접근으로 개인 신원을 검증했다고 표시하지 않는다. 다른 점포 자료는 보이지 않아야 한다.

게시 후 수정은 이전 내용을 덮어쓰지 않고 정정 버전으로 남긴다. 이전 읽음은 이전 버전에 보존하고 새 버전은 미확인으로 표시한다. 인계가 없거나 확인되지 않으면 근무 중 구두·기존 채팅으로 회복하고 사후 기록임을 표시한다. 점주가 직원 대신 읽음을 만들지는 않는다.

종료 후 제공자 접근을 회수하고 고객에게 사본을 남긴다. 보존·삭제 방식은 결제 전 안내한다. 큰 터치 영역, 명시적 레이블, 키보드 접근, 색상 외 상태 문구를 적용한다. 소라는 직원·점주 역할별로 작성→읽음→조회와 정정 후 미확인 이해를 관찰한다. 이는 예정된 확인이며 테스트 통과 기록은 아니다.

**현금 배분:** 도구 예약 100,000원, 모집 100,000원, 비구매 연계 사례비 120,000원, 소재 30,000원, 결제비 예약 20,000원, 돌발비 150,000원, 미배정 280,000원 = 800,000원. 월 고정비 60,000원은 도구 예약에 포함한다. 환불 전까지 수납금은 지출 재원으로 쓰지 않는다.

산술 도구 반환값과 위 표를 대조했고 원 단위 반올림했다. 비용 가정 자체는 미검증이다. 실제 지원·획득비가 높거나 29,000원 결제가 성립하지 않으면 가격·제공량을 재설계한다. 획득비는 모집 현금과 모집 시간 환산액을 같은 신규 유료 점포 수로 나눠 별도 보고한다.

## 6. 인계 완료 기준

다음은 **예정된 인수 시나리오**다.

- 직원이 저장 실패 후 재시도하면 내용이 보존되고 인계는 한 건만 남는다.
- 다음 교대가 읽음을 누르면 점주에게 확인 상태가 보이며 업무 완료로 표시되지 않는다.
- 읽은 메모가 정정되면 과거 이력과 새 미확인이 구분된다.
