# 비용·거래처 답변 모음

모두 부가세 포함 금액이며 합성 견적이다.

| 항목 | 단위와 기간 | 현재 상태 |
| --- | --- | --- |
| 문화센터 상담실 | 110,000원 / 10월 1일~31일 전체 | 9월 25일 결제 완료. 이 기간 토·일 예약 시간에 사용. 도중에 그만둬도 일할 환급 없음. |
| 휴대용 확대 화면 대여 | 기본 66,000원 / 30일 | 아직 주문하지 않음. 아래 단기 견적 회신 있음. |
| 예약·안내 문자 도구 | 44,000원 / 운영 계정·월 | 가입 전. 가입일 기준 한 달치 선결제. 최소 몇 개월을 써야 하는지 견적란이 비어 있어 문의 중. |
| 안내지 인쇄 | 8,000원 / 20장 묶음 | 아직 주문하지 않음. 배송비 없음. |
| 고객용 종이 안내책·소모품 | 6,000원 / 참여자 1명 | 무료 참여자에게도 지급. |

화면 대여업체, 9월 25일 문자: “10월 4일~17일 14일 대여는 33,000원으로 가능합니다. 18일 오전 10시 반납입니다. 9월 29일까지 이 조건으로 신청하시면 됩니다. 이후 연장은 하루 2,400원이고 재고 확인 후 확정합니다.”

문자 도구업체 답변: “월 단가는 44,000원입니다. 최소 이용 개월 수는 담당자가 확인해서 회신하겠습니다.” 아직 답이 오지 않았다. 발송 한도는 첫 운영 예상량 안에 들지만 무료 대체 도구의 기능과 사용 조건은 확인하지 않았다.
