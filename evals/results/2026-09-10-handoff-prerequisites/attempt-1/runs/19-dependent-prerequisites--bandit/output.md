# ‘맞은편’ 4주 파일럿 명세

**기간: 2026-10-05~11-01, 모든 시각은 한국시간.** 기존 두 동아리의 무료 약속 8묶음을 우선 이행하고, 신규 개인 고객에게 **30,000원짜리 장면 묶음 최대 2개**를 유료로 제공하는 안을 제안한다. 신규 제공은 2주 차에 한정해 사용·수정 관찰 시간을 확보한다.

이 문서는 실행을 위한 제안이다. 모집·연락·결제·구현은 수행하지 않았다. F4의 기존 수락은 확정 조건이며, 그 밖의 가격·운영 절차·판정 기준은 제안이다.

## 1. 근거와 선택

근거는 모두 제공된 **합성 자료**다. 실제 수요나 성능을 입증하지 않는다.

| 근거 | 해석과 결정 |
|---|---|
| F1-A~C, 9/24: 수작업 인력·현금 제약 | 앱 없이 기존 양식·문서·파일 공유 도구로 제공한다. |
| F2, 9/18~22: A의 자기 녹음, B의 파일 선호, D의 큰 글자 요구 | 상대역 음성＋큰 글자 대사표로 혼자 연습하는 과정을 지원한다. |
| F2: C의 대본 변경, E의 설정 부담 | 대본 버전을 고정하고 쉼은 기본/긴 쉼 중 하나만 선택한다. |
| F2: B의 8,000~12,000원 발언, F의 공동 예산 결정 | 가격 발언은 구매가 아니다. 개인 결제를 먼저 시험하되 동아리 구매 가능성을 별도로 확인한다. |
| F3-A~C, 9/23: 합성 장면 3개 제작 기록 | 알려진 크기 한도를 유지하고, 수정 시간을 미리 예약한다. |
| F4-A~C, 9/24: 두 동아리 수락 | 무료 4명에게 두 차례씩 제공하는 약속과 느린막의 비공개·삭제 조건을 우선한다. |

**대상:** 현재 장면을 연습하는 성인 생활연극 배우. 사용자는 배우, 개인 상품의 구매·승인자는 본인이다. 동아리 상품은 배우가 사용하지만 운영진이 구매하고 예산권자가 승인한다. 휴식 중인 사람의 복귀, 연기력·공연 성과 개선은 이번 검증 대상이 아니다.

| 선택지 | 장점 | 한계와 판단 |
|---|---|---|
| 자기 녹음·동료 상대역 | 무료이며 이미 쓰는 대안 | 직접 녹음·정지 조작 또는 상대의 시간이 필요하다. 비교 기준으로 유지한다. |
| 개인 장면 단건 | 구매 결정이 단순하고 작업 단위가 명확함 | 낮은 지불 의향과 충돌한다. **이번 실행안**으로 실제 구매 여부를 확인한다. |
| 동아리 묶음 구매 | 공지 경로가 있고 여러 배우에게 제공 가능 | 역할마다 별도 제작이며 할인 근거가 없다. 공동 승인도 미확인이다. 후속 견적 연구로 남긴다. |
| 월 구독·자동화 앱 | 반복 제공 가능성 | 변경량·유지 수요·다음 달 인력이 미확정이다. 보류한다. |

## 2. 하나의 제공 범위

**D1 — 장면 묶음:** 배우 1명 × 대본 버전 1개 × 역할 1개 × 쉼 종류 1개.

- 입력 한도는 **2쪽 이하, 상대역 대사 24개 이하, 상대역 음성 합계 3분 이하를 모두 충족**하는 장면이다.
- 결과물은 상대역 음성과 자기 차례의 쉼을 넣은 음성 파일 1개, 역할·버전·쉼 종류를 표시한 큰 글자 대사표 PDF 1개다.
- 같은 대본·역할의 쉼 또는 읽기 오류 수정 1회를 포함한다. 두 쉼 버전 동시 제공은 포함하지 않는다.
- 내용·역할 변경은 새 묶음이다. 기존 파일은 반복 사용 가능하지만 작품 전체 갱신은 제공하지 않는다.
- 영상 분석, 연기 지도, 실시간 상대역, 고객 음성 복제, 앱 개발은 제외한다.
- 기본/긴 쉼의 실제 길이는 도담·소리가 10/05 합성 예시로 정해 신청 안내에 초 단위로 표시한다. 아직 측정·확정되지 않았다.

**D2 — 신규 가격:** 총 결제액 30,000원/묶음, 1인 1묶음, 최대 2명. 납기·입력·권한·개별 전달 경로 확인 후 결제한다. 기존 무료 참여자에게 소급 적용하지 않는다.

### 선행 입력과 복구 창

**입력 보완과 전달 후 수정은 별도 절차다.**

- 화요일 18시까지 제작 가능한 입력이 되면 정상 화요일 녹음으로 넘긴다. 누락 상태와 다음 확인 시각을 참가자에게 표시한다.
- 화요일을 놓쳤어도 수요일 18시까지 보완을 받으면 목요일 12시까지 재검수한다. 4건 모두 목요일 제작으로 밀린 경우 소리의 공통 작업 20분＋녹음 140분을 예약하고, 도담은 완성되는 순서대로 건당 검수·전달 20분을 수행한다. 19시 시작 기준 마지막 전달은 22시 안에 배치할 수 있다. 해당 목요일의 다른 수정은 충돌 여부를 확인해 다음 가능한 슬롯을 개별 안내한다.
- 목요일 12시 이후에도 불완전하거나 분량을 초과하면 원래 납기를 보장할 근거가 없다. 도담이 당일 사유와 가능한 다음 화·목 제작일을 제시한다. **기존 약속을 자동 취소·변경하지 않으며**, 일정 변경은 당사자와 합의할 항목으로 남긴다.
- 신규 유료 건은 10/13 12시까지 입력과 결제가 완료된 경우만 받는다. 미완료 건은 결제를 요청하지 않고 이번 회차 대기로 전환한다.

### 수정·문의의 마지막 연결

전달 직후부터 수정 요청을 받는다. 화·목 12시까지 도담이 요청을 검토한 건은 해당일 19~22시 소리가 처리하고, 다음 날 12시까지 검수·재전달한다. 그 이후 요청은 다음 작업 창을 안내한다.

10/29 12시까지 접수하면 목요일 최종 녹음 후 **10/30 12시 재전달 → 10/31 12시 고객 확인 → 11/01 12시 도담 답변·접근 복구**가 가능하다. 고객이 그 시간에 확인할 수 있는지는 사전에 확인한다.

이는 기존 무료 건의 수정 권리를 없애는 마감이 아니다. 10/29 이후 음성 수정이나 마지막 수정본의 재오류는 4주 인력으로 완료를 보장할 수 없다. 도담이 11/01까지 구체적인 후속 일정·담당 자원과 당사자 합의를 확보해야 하는 **미해결 의무**로 기록한다. 다음 달 소리의 참여를 가정하지 않는다.

신규 고객에게는 위 접수 창을 결제 전에 고지한다. 제작자 실수는 포함 수정 횟수를 차감하지 않는다. 반복 오류·미제공으로 기간 안에 사용할 자료를 제공하지 못하면 신규 건은 전액 환불한다. 제작 전 취소도 전액 환불한다. 적용할 결제·환불 방식의 실제 처리 조건은 모집 전 확인한다.

## 4. 인력과 현금

F3 기준 묶음당 도담 40분, 소리 45분은 **수정 여유 포함**이다. 미사용 수정 시간으로 추가 판매하지 않는다.

| 도담 추가 배정 | 매주 상담·회신 120분, 모집·유료 제안 60분, 조사·회고 60분 |

도담의 제작 관련 시간은 1·3주 각 200분, 2주 120분, 4주 40분으로 예약하고, 수정 이동 시 여유 시간으로 옮긴다. 1·3주의 목요일 복구에는 도담 80분을 연속 확보한다. 신규 신청은 최대 6건, 비적격·대기 안내는 건당 10분을 모집 시간 안에 배정한다.

소리는 정상 1·3주 화요일에 공통 20분＋원본 140분을 예약한다. 각 주 목요일에는 최대 10건분 수정 100분도 들어갈 수 있지만, 원본이 목요일로 밀리면 동시에 약속하지 않는다. **새 모집을 중단하는 것과 기존 의무를 마치는 것은 별개**다.

다음 달 내부 임금 가정으로 묶음 직접 노동비는  
40/60×15,000＋45/60×20,000＝**25,000원**이다. 가격 12,000/30,000/40,000원에서 직접 노동 차감액은 각각 −13,000/5,000/15,000원이다. 결제 수수료·세금·모집·공통 작업비 차감 전이므로 이익이 아니다.

주간 공통 노동비만 약 16,667원으로, 30,000원 가격에서는 최소 4묶음의 기여액이 필요하다. 다른 비용까지 고려하면 더 필요하며 수요는 미확인이다. 이번 전체 계획 노동비는 약 556,667원으로, 낮은 협업비 덕분의 현금 적합성을 지속 수익성으로 해석하지 않는다.

*계산 확인: 읽기 전용 JavaScript 산술 도구 실행 결과 7묶음, 530분, 1,520분, 여유 400분, 예산 300,000원, 직접 노동비 25,000원을 확인했다. 제품 코드·테스트는 실행하지 않았다.*

| 수정·종료 | 문제 위치·원하는 수정 → 접수 상태·예정일 → 수정본 확인. 구본을 최신본으로 오인하지 않도록 표시 |

휴대폰에서 읽기 쉬운 단일 열, 명확한 버튼 이름, 키보드 접근, 색에만 의존하지 않는 오류 문구를 사용한다. 화면 잠금 재생은 아직 검증되지 않았으므로 호환 기기 확인 전 홍보하지 않는다.

자료는 해당 배우와 작업 담당자만 접근한다. **링크 소지만으로 본인 권한을 보장한다고 간주하지 않는다.** 도담은 참가자가 확인한 개별 경로와 수신자 제한을 점검한다. 운영진에게 개인 파일·명단을 전달하지 않는다.

느린막 원본·작업본·공유본은 늦어도 **11/08까지 삭제**해야 한다. 권고 실행일은 11/01로 잡고 도담의 마감 시간에 포함한다. 전체 참가자에게 같은 보관 원칙을 제안하며 회고에는 내용 없는 집계만 남긴다. 고객이 내려받은 사본을 원격 삭제할 수 있다고 약속하지 않는다.

도담은 10/05에 권리 확인 범위와 도구의 접근·삭제·결제 조건을 먼저 확인할 연구 목록을 만든다. 외부 조사 금지로 법적 충분성이나 도구 동작은 이번 문서에서 확정하지 않았다. 추후 확인 시 공식 출처·확인일을 기록하고, 충족되지 않는 경로의 신규 약속은 보류한다.

11/01 회고에서 무료 반복 사용, 신규 지불, 실제 노동시간을 분리해 판단한다. 반복 사용은 있으나 개인 결제가 없으면 예산권자 전원이 보는 동아리 단건 견적을 다음 실험으로 검토한다. 사용도 적으면 가격 인하보다 장면 선정·쉼·접근 문제를 먼저 확인한다. 다음 달 판매는 인력·가격·지원 기간이 확보된 뒤 결정한다.
