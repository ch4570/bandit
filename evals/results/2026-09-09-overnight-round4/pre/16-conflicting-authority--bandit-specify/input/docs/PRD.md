# TeamSlate 작업보드 PRD

합성 평가용 프로젝트. 문서, 인물, 정책과 실행 기록은 모두 가상이다.
문서 상태: v2 개발 인계 초안. 제품 책임자: 윤서.

## 1. 제품과 객체

TeamSlate는 조직 구성원이 작업과 댓글을 공유하는 내부 작업보드다.
작업과 댓글은 각각 고유 ID, 소속 조직 ID, 작성자 ID, 작성 시각을 가진다.
조직은 공유 콘텐츠의 소유 주체이며 작성자의 개인 계정과는 구별한다.

## 2. 기존 공통 동작

R-01: 현재 조직 구성원은 그 조직의 작업과 댓글을 읽는다. 작성자만
자신의 작업 본문을 편집하고, 작업 담당자는 상태를 진행 중 또는 완료로
바꾼다. 댓글 내용은 작성 후 편집하지 않는다.

R-02: 조직 A의 구성원 자격만으로 조직 B의 콘텐츠를 읽을 수 없다.
작업 완료는 삭제가 아니며 완료된 작업에도 기존 댓글이 남는다.

## 3. 조직 탈퇴 흐름

v2에는 구성원이 조직 설정에서 스스로 탈퇴를 요청하는 진입점을 추가한다.
현재 초안에는 요청 이후 처리와 표시 동작이 아직 정리되지 않았다.
적용 문서: [멤버십 탈퇴 정책](../policy/membership-departure.md),
[기여 기록 정책](../policy/contribution-records.md).

## 4. 탈퇴 수용 기준

자체 탈퇴 흐름의 수용 시나리오는 작성 전이다. 구현이나 실행 결과는 없다.

## 5. 기존 실행 기록

V-01 — 2026-08-20, v1.8 스테이징, 합성 조직 A/B: A 구성원의 B 작업
직접 주소 조회 2건이 거부되어 통과했다. 운영 환경은 검사하지 않았다.

V-02 — 2026-08-21, v1.8 스테이징: 운영자가 콘솔에서 구성원 한 명을
수동 제외한 뒤 그 사용자의 새 작업 조회 요청 1건이 거부되어 통과했다.
이미 열린 화면에서의 저장, 사용자 자체 탈퇴, 기여자 이름 표시는 검사하지 않았다.

## 6. 이번 배포 밖

내보내기, 조직 간 작업 이동, 댓글 편집, 계정 전체 삭제, 재가입 흐름은
이번 범위 밖이다. 별도 디자인 시스템이나 로그인 서비스를 만들지 않는다.
