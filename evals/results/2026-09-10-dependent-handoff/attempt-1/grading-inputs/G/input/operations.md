# 합성 운영 메모 — 확보한 사람과 시간

운영자는 9월 14~18일 합계 150분을 모집 안내·신청 폼·작업 서식 준비에 사용할 수 있다. 이 기간에 고객 주문 디자인을 대신 만들 수는 없다. 9월 21일~10월 2일에는 고객 응대와 주문 운영에 합계 240분을 쓸 수 있다. 두 시간 예산은 서로 옮길 수 없다.

외부 디자이너의 작업 시간은 아래 두 번으로 확정했다. 다른 날이나 추가 인력은 확보하지 않았다. 두 창 모두 비용 지급이 확정되어 있다. 각 창 안의 시간을 남겨 다음 창에 더할 수는 없다.

| 제작 창 | 가능한 작업 시간 |
| --- | --- |
| 9월 24일 18:00~21:00 | 180분 |
| 9월 30일 18:00~21:00 | 180분 |

현재 제공 가능한 기본 결과물은 작가 1명당 상품 최대 3개의 A6 안내카드 묶음이다. 고객이 제공한 사진·상품명·가격·재질·크기·관리법을 기존 레이아웃에 배치한다. 디자이너는 사진 보정, 촬영, 로고 제작, 상품 사실 조사, 새로운 편집 도구 교육은 맡지 않는다. 편집 가능한 기존 템플릿을 전달하는 것은 가능하다. 고객은 내용과 이미지 사용 권한의 원천이며, 운영자는 읽기 어려운 문장과 누락을 확인한다.

작업량 측정용 내부 리허설에서 주문당 다음 시간이 들었다. 숙련도가 크게 달라진다고 가정하지 않는 한 이 수치를 계획에 쓸 수 있다.

| 작업 | 담당 / 분 |
| --- | --- |
| 입력 확인·누락 요청 한 번 | 운영자 / 12 |
| 초기 카드 제작·미리보기 생성 | 디자이너 / 35 |
| 고객 피드백 한 번을 모아 작업 지시 | 운영자 / 8 |
| 모인 피드백 반영 한 번 | 디자이너 / 15 |
| 최종 파일 내보내기 | 디자이너 / 5 |
| 파일 전달·사용 안내 | 운영자 / 4 |

모집·결제 명단 관리와 종료 정리에 운영자 48분이 별도로 필요하며 240분에 포함된다. 신청 전부가 주문으로 연결되지 않아도 이 48분은 든다. 추가 고객 대응이나 추가 수정은 공짜 시간이 아니다. 처음부터 수정 없는 결과물이나 초안·템플릿만 판매할 수도 있으나 결과물과 책임 범위를 고객에게 분명히 알려야 한다.

현재는 간단한 폼, 계좌 또는 결제 링크, 문자, 공유 폴더로 운영한다. 폼과 안내 화면의 디자인은 준비 기간에 운영자가 할 수 있다. 실제 카드의 시각 디자인은 확보한 제작 창에서만 가능하다. 인쇄·배송은 서비스에 포함되어 있지 않다. 완성된 파일을 받은 작가가 인쇄소를 선택하고, 운영자가 확인한 인쇄소의 이 마켓용 파일 접수 마감은 10월 5일 정오다. 인쇄소 일정과 가격은 이후 바뀔 수 있으므로 전달 안내에 확인 책임을 남겨야 한다.
