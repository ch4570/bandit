### 4. 고객 화면과 운영 인계

**R1 — 신청 화면**

`상품·가격·일정 → 포함/제외 → 상품별 입력·사진 → 확인 가능 여부 → 환불 조건 → 신청`

버튼은 **‘자료 제출하기 — 아직 결제되지 않습니다’**로 쓴다. 필수항목 누락은 해당 항목에 문자로 표시한다. 확인 일정이 맞지 않거나 제외 작업이 필요한 신청에는 사유를 안내하고 결제받지 않는다. 만석이면 ‘이번 모집 종료’를 표시한다.

**R2 — 결제 안내**

자료가 완비된 고객에게 주문번호, 상품 수, 4만원, 납기, 확인 마감, 결제 방법을 한 번에 보낸다. 운영자가 입금을 확인하면 ‘주문 확정’, 확인 전에는 ‘입금 확인 중’으로 표시한다. 중복 입금은 추가 주문으로 처리하지 않는다.

**R3 — 초안 확인**

`주문번호·초안 v1 → 상품별 미리보기 → 가격/크기/관리법 확인 → 수정 없음 또는 수정할 문장 → 제출`

고객의 열람은 승인이 아니다. 제출한 수정 내용은 마감 전 교체할 수 있고, 운영자는 **마감 시점의 마지막 응답 한 묶음**만 반영한다. 사실 변경은 고객이 정확한 대체 문장을 제공해야 한다. 최종 파일은 그 요청을 반영하며 추가 고객 승인 회차는 두지 않는다.

**R4 — 최종 전달·복구**

`최종 v2 → PDF 다운로드 → 이미지로 내용 확인 → A6 실제 크기 인쇄 안내 → 인쇄소 일정 직접 확인`

링크가 열리지 않으면 문자로 회신하게 하고 10월 2일까지 첨부파일로 재전송한다. 사실 오류가 발견되면 해당 카드는 사용하지 않도록 알린다. 확보된 제작 시간 안에 수정할 수 없으면 납기 연장을 강요하지 않고 전액 환불한다.

**제안 환불 정책:** 제작 전 취소, 고객 확인 마감 누락, 약속한 결과물 미제공은 전액 환불. 제작 후 단순 변심은 환불 제외로 결제 전에 명시한다. 환불 수수료가 반환되는지는 미확인으로, 아래 기본 손익에는 반영하지 않았다.

**계속 검토:** 5명 결제, 전원 정시 납품, 실제 시간을 포함한 반복 손익이 음수가 아닐 때. 그래도 다음 달 디자이너 시간·단가를 확인하기 전 재판매하지 않는다.

**변경:** 결제는 있으나 시간이 초과되면 가격·입력 조건·수정 범위를 재설계한다. 사용 확인이 없으면 효과는 미확인으로 남긴다.

**중단 또는 보류:** 납기 실패·사실 오류가 발생하면 신규 판매를 멈추고 복구한다. 적격 고객에게 제안했는데 결제가 없다면 현재 상품의 유료 출시를 보류한다. 적격 신청 자체가 적으면 가격 실패로 단정하지 않는다.
