**5. 디자이너·개발자 인계**

다음은 제안 요구사항이다. 객체는 점포, 날짜·송신/수신 교대, 인계 항목, 해당 항목의 읽음 기록이다.

| 화면 | 내용 순서·주요 행동·상태 |
|---|---|
| 점주 신청·확정 | 대상 조건 → 가격·기간·지원·환불 → 신청. 가온의 자격·수납 확인 전에는 ‘신청 중’, 확인 후 ‘이용 확정’ |
| 첫 접근 | 점포명 → 역할·현재 교대 → 읽음 의미 안내 → 샘플 연습. 직원 경로와 점주 관리 경로 분리 |
| 직원 인계 목록 | 받을 교대·날짜 → 미읽음 항목 → 읽음 항목 → ‘인계 남기기’. 빈 화면은 ‘등록된 인계 없음’; 인계 성공으로 표시하지 않음 |
| 항목 작성·확인 | 대상 교대 → 내용 → 저장. 다음 교대가 본문을 읽고 ‘읽었습니다’ 선택. ‘업무 완료 아님’ 상시 표시 |
| 점주 조회 | 날짜 → 메모 없음/미읽음/읽음 → 항목과 시각. 점주 조회 자체는 직원 읽음을 바꾸지 않음 |

- 직원은 점포 접근 경로와 점포 코드를 사용한다. 개인 신원을 검증하지 않으므로 **개인별 열람 증명이나 전원 확인을 주장하지 않는다.** 다음 교대의 공동 확인임을 표시한다.
- 점주는 별도 관리 접근으로 조회·접근 재발급을 요청한다. 직원 경로로 결제·접근 관리·다른 점포 조회를 할 수 없다. 퇴사·유출 시 가온이 경로를 교체하며 기존 기록은 유지한다.
- 저장된 원문은 덮어쓰지 않는다. 정정은 새 항목으로 연결하고 새 읽음이 필요하다. 반복 클릭은 같은 항목·교대의 읽음을 중복 생성하지 않는다.
- 미읽음은 유지되며 다음 근무 중 담당자가 확인한다. 긴급 업무는 기존 매장 연락 절차를 사용한다. 퇴근자에게 응답을 요구하지 않는다.
- 저장 실패는 실패 문구와 재시도를 제공하며 완료 표시하지 않는다. 읽음 실패도 미읽음으로 남긴다. 접근 불가는 점주에게 새 경로 요청을 안내한다.
- 모바일에서 큰 터치 영역, 명시적 버튼 이름, 키보드 접근, 색상 외 상태 문구를 제공한다.

소라는 2주차에 점주 2명·직원 2명에게 첫 접근, 정정 항목 확인, 미읽음 해석 과제를 준다. 완료 여부와 읽음/완료 혼동을 기록하고, 한 명이라도 혼동하면 문구·상태를 수정한다.

**6. 사업모델과 경제성**

입력은 `costs-and-delivery.md`의 월 비용 가정이다. 동일한 제공물에 대해 점주가 점포 단위로 지불한다.

| 모델 | 점포당 반복 월 잔여액 | 5곳 반복 월 손익 | 온보딩 포함 첫 달 5곳 손익 |
|---|---:|---:|---:|
| A: 월 29,000원, 도입비 없음 | 13,543원 | 7,715원 | −75,618원 |
| B: 도입비 39,000원 + 월 19,000원 | 3,873원 | −40,635원 | 64,597원 |

잔여액 = 가격×0.967 − 저장·알림 2,000 − 지원 12,500. 전체 손익은 잔여액×점포 수 − 고정비 60,000이다. 첫 온보딩 인건비는 점포당 16,667원이며 B의 도입비에는 결제 수수료를 차감했다.

**잠정 추천은 A다.** B는 초기에 현금을 회수하지만 반복 손익분기점 16곳이 지원 한도 5곳을 넘는다. A도 손익분기점 5곳이며 여유가 작다. 지원이 월 15/30/60분이면 A의 5곳 손익은 각각 38,965/7,715/−54,785원이다. 지원 시간이 늘거나 29,000원 결제가 거절되면 가격·제공 범위를 재설계한다.

14일 실험은 별도 학습 상품이다. 지원 15분, 저장비는 보수적으로 월 전액, 온보딩 전액을 적용하면 점포당 잔여액 **−10,508원**, 5곳과 월 고정비 포함 **−112,542원**이다. 인건비 환산을 포함한 수치이며 현금 지출과 다르다. 개발·디자인 유지비와 획득비는 위 손익에 미포함이므로 순이익·장기 수익성으로 부르지 않는다.

계산은 JavaScript 도구로 실행해 위 값과 대조했다. 비용·지원 시간 가정의 타당성까지 검증한 것은 아니다.

**7. 인수 기준과 종료 판단**

아래는 모두 **계획된 확인이며 미실행**이다.

- 직원이 저장하면 새로고침 후에도 같은 교대 항목이 보인다. 실패하면 저장 완료로 보이지 않는다.
- 다음 교대가 읽음을 선택하면 점주에게 해당 항목의 읽음 시각이 보이고, 업무 완료로 표시되지 않는다.
- 정정 항목은 기존 읽음을 승계하지 않는다. 중복 클릭은 집계를 늘리지 않는다.
- 직원 접근으로 점주 관리나 타 점포에 접근할 수 없고, 폐기된 경로는 차단된다.
- 마지막 모집 점포도 9/28~10/11 전체 이용, 결과 확인, 요청·종료 처리를 받는다.

기존 정식 명세는 없으며, 본안은 미정이던 제공물·읽음 규칙·기간·가격을 연결한 신규 제안이다. 가온은 10/11 실제 결제·사용·지원 시간으로 계속/수정/중단을 결정한다. 이후 지원 인력은 미확정이므로 월 서비스 판매는 그 자원이 확보된 뒤 진행한다.
